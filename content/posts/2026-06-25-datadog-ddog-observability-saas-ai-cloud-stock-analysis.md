AIとクラウドへの投資が世界規模で加速する中、「誰がシステムを見張るか」という問いに答え続けているのが[Datadog](https://www.datadoghq.com/)（NASDAQ: DDOG）ですわ。今回はこの可観測性（オブザーバビリティ）SaaSのリーダーを徹底分析します。

---

## Datadogとはどんな企業か

Datadogは2010年創業、2019年にNASDAQに上場したクラウドネイティブなモニタリング・分析プラットフォームです。

企業がクラウド上で動かすアプリケーション・サーバー・ネットワーク・セキュリティを**一元的に監視・可視化・分析**するサービスを提供しています。

### 主要プロダクト

| 製品 | 内容 |
|------|------|
| Infrastructure Monitoring | サーバー・コンテナのメトリクス監視 |
| APM（Application Performance Monitoring） | アプリの性能・レイテンシ分析 |
| Log Management | ログの収集・検索・アラート |
| Security Platform | クラウド環境の脅威検出・CSPM |
| AI Observability | LLMアプリのコスト・品質・レイテンシ監視（新機能） |

---

## AI時代に注目される理由

### 1. AIアプリが「もう1つのクラウド需要」を生む

ChatGPTやClaude、企業内AIエージェントが急増する中、これらのLLMアプリを本番運用するには**監視が不可欠**です。

Datadogは「LLM Observability」という機能でいち早くAIアプリの監視市場に参入。トークン消費コスト・レスポンス品質・エラー率を可視化できます。

> 企業が「AIを動かす」だけでなく「AIを安定運用する」フェーズに移行するほど、Datadogへの需要は高まりますわ。

### 2. クラウド支出増 = Datadogの売上増

Datadogの課金モデルは**使用量ベース（Usage-based Pricing）**。監視対象のホスト数・ログ量・APMスパン数に比例して課金されます。

AWSやAzure、GCPへのクラウド投資が増えるほど、Datadogの売上も自然に伸びる構造ですわ。

### 3. プラットフォーム化による「のり付き効果」

Datadog導入企業が使うプロダクト数は年々増加しています。

- 2020年：平均2製品以上 約70%
- 2024年：平均5製品以上 約50%超

一度Datadogで監視環境を構築すると移行コストが高く、解約率（チャーン）が極めて低い特徴があります。

## 財務状況（2025年度実績）

| 指標 | 数値 |
|------|------|
| 売上高 | 約28億ドル（前年比+26%） |
| 粗利益率 | 約81% |
| 営業キャッシュフロー | プラス転換・拡大中 |
| ARR（年間経常収益） | 年率成長継続 |
| NRR（純収益維持率） | 110%超 |

NRR（Net Revenue Retention）が110%を超えるということは、**既存顧客だけで毎年10%以上売上が増える**ことを意味します。新規開拓コストをかけなくても成長できる極めて健全なモデルですわ。

## 競合との比較

| 企業 | 強み | 弱み |
|------|------|------|
| **Datadog** | プラットフォーム統合・AI対応・UI | 価格が高め |
| New Relic | 歴史・エンタープライズ実績 | クラウドネイティブ遅れ |
| Dynatrace | AI自動化機能 | 導入複雑・価格高 |
| Grafana（OSS） | 無料・カスタマイズ性 | サポート・統合は劣る |
| AWS CloudWatch | AWS内完結 | マルチクラウド対応弱 |

DatadogはマルチクラウドかつAIネイティブという点で独自のポジションを持っています。

---

## リスク要因

### 1. クラウド支出の最適化（FinOps）

企業がコスト削減でクラウド利用量を絞ると、Datadogの収益にも影響が出ます。2022〜2023年に一度この逆風を経験しました。

### 2. 競合の激化

AWSやMicrosoftが自社監視ツールを強化しており、クラウド内に閉じたユーザーがDatadogを必要としなくなるリスクがあります。

### 3. バリュエーションの高さ

PER（株価収益率）・PSR（株価売上高倍率）ともに高水準で推移しており、成長期待が株価に織り込まれています。成長鈍化時の株価下落リスクには注意が必要ですわ。
