## 銀ETFとは？金とどう違うのか

前回の[金ETF（GLD・IAU・GLDM）完全ガイド](/posts/2026-06-05-gold-etf-gld-iau-gldm-complete-guide/)に続き、今回は**銀（シルバー）ETF**を解説します。銀は「工業用途を持つ貴金属」として、純粋な価値保存手段に近い金とは異なる独自の特性を持っています。

銀の需要は大きく2種類に分かれます。

- **投資・貴金属需要**：インフレヘッジ・安全資産としての保有
- **工業需要**：太陽光パネル・電子部品・EV・医療機器など

この二重構造が銀の魅力であり、リスクでもあります。景気拡大局面では工業需要の増加で金よりも大きく上昇する可能性があり、一方で景気後退局面では工業需要の落ち込みが金以上の下落を引き起こすことがあります。

現物の銀を保有するには保管コスト・盗難リスクなどの問題がありますが、**銀ETF**を使えば証券口座から簡単に銀価格に連動した投資ができます。

## 主要銀ETF 3本の概要

### ① SLV（iShares Silver Trust）

**ブラックロック**が運用するSLVは、銀ETFの中で最も歴史が長く（2006年設立）、最大の運用資産規模を誇ります。

| 項目 | 数値（2025年末時点） |
|------|----------------|
| 設定日 | 2006年4月 |
| 運用会社 | iShares（BlackRock） |
| 経費率 | 0.50% |
| 運用資産 | 約110億ドル |
| 1日平均出来高 | 非常に高い（流動性最高クラス） |
| 裏付け方式 | 現物銀（ロンドン保管） |

SLVは1口あたり約0.93オンスの現物銀に裏付けられています（ETF設定時は1オンスで開始したが、経費率分だけ徐々に減少）。流動性が非常に高く、機関投資家にも広く使われています。

**向いている人：**
- 流動性を重視する方
- 既にブラックロック製品（IVV・IAUなど）でまとめたい方
- 短期トレードも視野に入れる方

---

### ② SIVR（abrdn Physical Silver Shares ETF）

旧称はETFS Physical Silver（ETFS Silver Trust）で、現在は**abrdn（アバディーン）**が運用しています。SLVとほぼ同様の現物裏付け方式ですが、経費率が若干低いのが特徴です。

| 項目 | 数値（2025年末時点） |
|------|----------------|
| 設定日 | 2009年7月 |
| 運用会社 | abrdn |
| 経費率 | 0.30% |
| 運用資産 | 約8億ドル |
| 1日平均出来高 | 中程度 |
| 裏付け方式 | 現物銀（チューリヒ・ロンドン保管） |

SLVに比べると規模・流動性は劣りますが、経費率の差（0.50% vs 0.30%）は長期保有では無視できない差になります。

**向いている人：**
- コスト意識が高く長期保有を考える方
- 中程度の流動性で問題ない方

---

### ③ PSLV（Sprott Physical Silver Trust）

**スプロット・アセットマネジメント**が運用するPSLVは、他の2本と一線を画す「純粋な現物保有重視」の商品です。銀地金をカナダ王立造幣局のヴォールト（金庫）に保管し、保有者は一定条件下で**現物の銀と交換する権利**を持ちます。

| 項目 | 数値（2025年末時点） |
|------|----------------|
| 設定日 | 2010年10月 |
| 運用会社 | Sprott Asset Management |
| 経費率 | 0.35% |
| 運用資産 | 約13億ドル |
| 1日平均出来高 | やや低め |
| 裏付け方式 | 現物銀（カナダ王立造幣局） |
| 現物交換 | 条件付きで可能 |

スプロットはゴールドバグ（金・銀の現物主義者）に根強い人気があります。「本当に現物が存在するか」に強いこだわりを持つ投資家に支持されています。

**向いている人：**
- 現物裏付けの透明性・信頼性を最重視する方
- 将来的な現物交換の可能性も視野に入れる方
- Sprott Goldファンド（PHYS）と合わせて使いたい方

## 銀ETFのリターン特性：金との比較

銀は「金よりボラティリティが高い」という特徴があります。過去のデータを見ると：

- **強気相場**：銀は金を大幅にアウトパフォームすることが多い（2020年は銀+47%、金+25%）
- **弱気相場・景気後退**：銀の下落幅が金より大きくなりやすい（2022年は銀-14%、金-2%）

この「レバレッジ効果のような動き」はゴールド・シルバー比率（GSR: Gold/Silver Ratio）として知られています。

### GSR（ゴールド・シルバー比率）とは

GSR = 金価格 ÷ 銀価格

歴史的な平均は60〜70程度ですが、2020年3月には**125倍**まで拡大（銀が相対的に割安）し、その後急反発。こうした極端な乖離は「銀への投資チャンス」として注目されることがあります。

2026年現在のGSRは80〜90程度で推移しており、歴史的平均より若干銀が割安な水準です。

## 銀の需給構造：工業需要がカギ

銀の需要の約50〜55%は工業用途です。主な用途は以下の通りです。

### 太陽光パネル（急成長中）
銀は太陽電池の電極に使用されます。1枚のパネルあたり約20〜30グラムの銀が必要で、世界的な再生可能エネルギーへの移行でこの需要は急増しています。

### 電気自動車（EV）
EV1台にはガソリン車より多くの銀が使用されます（電気システム・センサー等）。EV普及が銀需要を底上げする構造的要因として注目されています。

### 電子部品・半導体
スマートフォン・PC・半導体製造プロセスにも銀は欠かせません。

### 医療・抗菌用途
銀の抗菌特性を利用した医療機器・創傷被覆材にも広く使われています。

**供給面**では銀は約70%が銅・鉛・亜鉛などの採掘時の副産物として生産されます。純粋に銀の価格が上昇しても供給が即座に増えにくい構造があります。

## 銀ETFのリスク

銀ETFに投資する際には以下のリスクを理解しておく必要があります。

### 1. 高いボラティリティ
銀は金の2〜3倍のボラティリティがあります。短期的に20〜30%の価格変動は珍しくありません。

### 2. 景気敏感リスク
工業需要が大きいため、景気後退局面では金よりも大きく下落する可能性があります。

### 3. 為替リスク
銀は米ドル建てで取引されます。円高進行時には円換算でのリターンが目減りします。

### 4. 流動性リスク（SIVR・PSLVの場合）
SLVに比べてSIVR・PSLVは規模・流動性が劣ります。大口投資家はスプレッドに注意が必要です。

### 5. 現物保有との税務上の違い
ETFは株式と同じ課税（特定口座対応）ですが、現物銀は譲渡所得扱いとなり課税方式が異なります。

## どの銀ETFを選ぶべきか

### 初心者・シンプルに使いたい → **SLV**
流動性が最高で、取引しやすく情報も豊富。ブラックロックブランドの信頼性も魅力。経費率は0.50%とやや高いですが、まず銀ETFを試してみたい方に最適です。

### コスト重視の長期投資家 → **SIVR**
経費率0.30%はSLVより0.20%安く、10年保有すれば約2%のコスト優位になります。流動性もそれなりにあるので、長期保有メインの投資家に向いています。

### 現物信仰・透明性重視 → **PSLV**
「紙の上の銀」ではなく「本物の銀が存在することの証明」を求めるなら、カナダ王立造幣局保管のPSLVが選択肢になります。流動性はやや劣りますが、スプロットの現物重視哲学に共鳴する方に。

## 銀ETFのポートフォリオへの組み入れ方

銀ETFをポートフォリオに組み込む場合、一般的には**全体の5〜10%以内**に留めることが推奨されます。

### 典型的な組み合わせ例

**ベーシック分散型（全世界株式メイン）**
- 全世界株式ETF（VT等）: 80%
- 債券ETF（BND等）: 10%
- 金ETF（GLD等）: 7%
- 銀ETF（SLV等）: 3%

**コモディティ強調型**
- S&P500 ETF（VOO等）: 60%
- 全世界株式（VT等）: 20%
- 金ETF: 10%
- 銀ETF: 10%

銀のみ単独で大きな比率を取ることはリスクが高いため、金ETFとセットで「貴金属・コモディティ枠」として合わせて10〜15%程度に収めるのが現実的です。

## 日本の個人投資家が銀ETFを買う方法

SLV・SIVR・PSLVはいずれも**米国ETF**です。日本の個人投資家が購入するには以下が必要です。

1. **外国株取引に対応した証券口座**（SBI証券・楽天証券・マネックス証券など）
2. **外国株取引サービスへの申込み**
3. **外貨決済**（米ドル建て）または**円貨決済**（証券会社によっては可）
4. **NISA（成長投資枠）での購入も可能**（ただし外国ETFは特定の商品に限られる）

NISA成長投資枠でSLVが購入できるかは証券会社・年度によって異なります。最新情報は各証券会社の対象銘柄リストで確認してください。

## 銀ETFと金ETFのどちらを選ぶか

| | 金ETF | 銀ETF |
|---|---|---|
| 安全資産性 | ★★★ | ★★ |
| 工業需要 | 低い | 高い |
| ボラティリティ | 中 | 高 |
| インフレヘッジ | 強い | 中程度 |
| 景気拡大恩恵 | 少ない | 大きい |
| 長期実績 | 豊富 | 限定的 |

**どちらかだけ選ぶなら金ETF**が安全資産・インフレヘッジとして安定しています。両方持つなら「金7〜8：銀2〜3」程度の比率が一般的です。

## まとめ：銀ETFは「工業用貴金属」への露出手段

銀ETFはコモディティ投資の中でも特異な位置にあります。安全資産としての側面と、工業用途による景気連動性を兼ね備えた「ハイブリッドなコモディティ」です。

- **流動性重視 → SLV**
- **コスト重視の長期投資 → SIVR**
- **現物透明性重視 → PSLV**

3本の中でどれを選ぶかは投資スタイルと優先事項によりますが、いずれも現物銀に裏付けられた信頼性の高いETFです。

金ETFや[ビットコインETF（IBIT・FBTC・BITB）](/posts/2026-06-06-bitcoin-etf-ibit-fbtc-bitb-complete-guide/)と組み合わせ、ポートフォリオの「オルタナティブ資産枠」として少量（5%以内）から試してみることをおすすめします。銀のユニークな需給構造とボラティリティを理解した上で、賢い資産分散の一手段として活用してください。
