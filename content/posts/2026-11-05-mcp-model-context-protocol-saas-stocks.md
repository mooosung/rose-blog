「MCP対応しました」というお知らせを、2026年に入ってから日本のSaaS企業でもよく見かけるようになりましたわね。

freeeは2026年3月2日に、会計・人事労務・請求書など**約270本のAPIをまとめてMCPツール化した「freee-mcp」**を公開。サイボウズもkintoneの公式MCPサーバーを出していますの。

では、そもそも**MCPとは何なのか**。なぜSaaS企業がこぞって対応しているのか。そして、それは株を持つ側にとって**追い風なのか、向かい風なのか**——この記事では、技術の細かい話はできるだけ省いて、投資家の目線で整理いたしますわね🌹

## MCPとは｜AIと外部ツールをつなぐ「共通の差し込み口」

**MCP（Model Context Protocol／モデル・コンテキスト・プロトコル）** は、AIアシスタントが外部のアプリやデータベースに接続して、情報を読んだり操作したりするための**オープンな共通規格**ですわ。

[Anthropic（アンソロピック）が2024年11月25日にオープンソースとして公開](https://www.anthropic.com/news/model-context-protocol)したもので、公式ドキュメントでは「AIのためのUSB-Cのようなもの」とたとえられていますの。

USB-Cが登場する前は、機器ごとに違う形のケーブルが必要でしたわよね。AIも同じで、MCP以前は「AIをSlackとつなぐ」「AIをGoogleドライブとつなぐ」たびに、**AI側とアプリ側の組み合わせごとに専用の連携を作る**必要がありましたの。

| | MCP以前 | MCP以後 |
|---|---|---|
| つなぎ方 | AI×アプリの組み合わせごとに専用連携 | アプリ側が「MCPサーバー」を1つ用意すれば、対応AIすべてから使える |
| 作る手間 | AIが5種類・アプリが100種類なら最大500通り | 5＋100通りで済む |
| 例え | 機器ごとに違う充電ケーブル | USB-C |

### 登場人物は「クライアント」と「サーバー」の2つだけ

- **MCPクライアント**：AIの側。Claude、ChatGPT、Cursor、Microsoft Copilot、VS Codeなど
- **MCPサーバー**：つながれる側。freee、kintone、Jira、Salesforceなどが「AIから使える窓口」として用意するもの

たとえばClaudeにfreeeのMCPサーバーをつないでおけば、チャットで「A社宛に請求書を作って」と頼むだけで、取引先の登録から請求書の発行までをAIが進めてくれますの。freee自身がプレスリリースでこの使い方を例に挙げていますわ。

## APIやプラグインと何が違うのか

「それって昔からあるAPIと同じでは？」と思われた方、鋭いですわ。実際、**MCPサーバーの中身の多くは既存のAPIを包み直したもの**ですの。freee-mcpも、2018年から提供してきたPublic APIをベースにしていますわ。

違いは「誰が使う前提か」ですの。

| | API | MCP |
|---|---|---|
| 使う人 | 人間のエンジニアがプログラムを書いて呼ぶ | **AIが自分で読んで、自分で呼ぶ** |
| 説明書 | エンジニア向けのドキュメント | 「このツールは何をするか」をAIが理解できる形で添付 |
| 接続先ごとの作業 | 連携ごとに開発が必要 | 対応AIなら設定するだけ |

ChatGPTのプラグインのような「特定のAI専用の拡張」とも違いますわ。MCPは**特定の会社のものではない共通規格**なので、一度作ればClaudeでもChatGPTでもGeminiでも使えますの。ここが普及した最大の理由ですわね。

## 2年で「業界標準」になるまでの流れ

| 時期 | できごと |
|------|---------|
| 2024年11月 | AnthropicがMCPを公開。Claude Desktopで利用可能に |
| 2025年3月 | 通信方式「Streamable HTTP」を導入。クラウド上のMCPサーバーが作りやすくなる。同月、OpenAIも対応を表明 |
| 2025年5月 | アトラシアンがJira・Confluenceの[リモートMCPサーバー](https://www.atlassian.com/ja/blog/remote-mcp-server)をベータ公開（Anthropicが最初の公式パートナー、Cloudflare上で稼働） |
| 2025年6月 | セールスフォースが「[Agentforce 3](https://www.salesforce.com/jp/news/press-releases/2025/06/27/agentforce-3-announcement/)」でMCPへのネイティブ対応を発表 |
| 2025年12月 | Anthropicが[MCPをLinux Foundation傘下の「Agentic AI Foundation」に寄贈](https://blog.modelcontextprotocol.io/posts/2025-12-09-mcp-joins-agentic-ai-foundation/)。月間SDKダウンロード9,700万回超、稼働中のサーバー1万以上 |
| 2026年3月 | freeeが「freee-mcp」を公式OSSとして公開 |
| 2026年7月28日 | 新仕様が正式リリース。セッション管理を撤廃する「ステートレス化」で、大規模なクラウド運用がしやすくなる |

特に大きいのは**2025年12月の寄贈**ですわ。Agentic AI Foundationは**Anthropic・OpenAI・Block**の3社が共同で設立し、Google・Microsoft・AWS・Cloudflare・Bloombergが支援する団体ですの。

LinuxやKubernetesと同じ中立の財団に移ったことで、「Anthropicの規格」から**「業界みんなの規格」**になりましたわ。競合のOpenAIが共同設立者に名を連ねている時点で、規格争いはほぼ決着したと見てよいでしょうね。

## SaaS企業はなぜMCPに対応するのか

ここからが投資家にとっての本題ですわ。

freeeの共同創業者でCAIO（最高AI責任者）の横路隆氏は、2026年2月の記者発表でこう話していますの。

> 「SaaSは人が使うものではなく、AIから使われるものになってきた」

これまでのSaaSは、**人間が画面を開いて操作する**ことを前提に作られていましたわ。使いやすい画面、わかりやすいボタン配置——それ自体が競争力でしたの。

ところがAIエージェントが仕事を代行するようになると、**画面を見るのはAIで、人間は結果を受け取るだけ**になっていきますわ。そのときAIから操作できないSaaSは、そもそも選ばれなくなってしまいますの。

MCP対応は「新機能」というより、**AI時代の最低限の参加資格**になりつつある、というのが実態ですわね。

### 主なSaaS企業のMCP対応状況

| 企業 | 証券コード／ティッカー | MCP対応の中身 |
|------|---------------------|-------------|
| セールスフォース | CRM | Agentforce 3でネイティブ対応（2025年6月発表） |
| アトラシアン | TEAM | Jira・Confluenceのリモートサーバー（2025年5月ベータ、のちに一般提供） |
| クラウドフレア | NET | リモートMCPサーバーを動かす基盤を提供。Agentic AI Foundationの支援企業 |
| freee | 4478 | 約270本のAPIを網羅した「freee-mcp」（2026年3月） |
| サイボウズ | 4776 | kintone・Garoonの公式MCPサーバー（Apache 2.0ライセンス） |

日本のSaaSで言えば、サイボウズの近況は[サイボウズ（4776）株価の見方](/posts/2026-10-29-cybozu-4776-stock-price-kintone-ai-q3/)、米国勢は[セールスフォース（CRM）の株価分析](/posts/2026-06-11-salesforce-crm-ai-saas-stock-analysis/)で詳しく書いておりますわ。

## 投資家目線：MCPはSaaS株の追い風か、向かい風か

結論から申し上げると、**両面ありますの**。どちらに転ぶかは、その会社が「何を持っているか」で決まりますわ。

### 追い風になる会社｜データと業務の「正本」を持っている

MCPはあくまで**AIとツールをつなぐ配管**ですわ。配管の先に**AIが読み書きしたい大事なデータ**がなければ、つながれる意味がありませんの。

- 会計・給与・顧客台帳のように、**法律や監査の上で「正しい記録」でなければならないデータ**を持つ会社
- 長年の業務ルール（承認フロー・権限管理）が組み込まれていて、**AIに丸ごと作り直させるのが危ない**領域

こういう会社にとって、MCPは**利用者の入口が増える**話になりますわ。人間のユーザーに加えて、AIエージェント経由の利用が上乗せされるからですの。

### 向かい風になる会社｜「画面の使いやすさ」が売りだった会社

逆に、データ自体は汎用的で、**使いやすい画面**で差をつけていた会社は苦しくなりますわ。AIが間に入ると、人間は画面を見なくなるからですの。

さらに見落とせないのが**課金モデル**ですわ。多くのSaaSは「利用者1人あたり月額いくら」の**座席課金**ですわよね。AIエージェントが10人分の作業をこなすようになれば、契約される座席数そのものが減りかねませんの。

この「SaaSの死」論については、[「SaaSの死」は本当か｜ソフトウェア銘柄を見極める3つのモノサシ](/posts/2026-09-17-saas-is-dead-ai-agent-software-stocks/)で、座席課金の何が壊れて何が壊れないのかを掘り下げていますわ。

![AIエージェント時代のSaaS銘柄を見極めるイメージ](/img/body/2026-11-05-mcp-model-context-protocol-saas-stocks-2.jpg)

### 決算資料でチェックしたい3つの点

1. **MCPやAPI経由の利用量を数字で出しているか**
   「AI経由の呼び出し回数」「エージェント経由の取引件数」などを開示し始めた会社は、AI時代の稼ぎ方を本気で設計していますわ
2. **課金が座席だけに頼っていないか**
   従量課金・成果課金・AIクレジットなど、**座席以外で売上が立つ仕組み**を持っているか。サイボウズが2026年11月18日に販売を始める「AIクレジット」はその一例ですの
3. **自社のAIエージェントも持っているか**
   つながれるだけの「部品」で終わるのか、自分もエージェントを動かす「司令塔」側に立つのか。セールスフォースのAgentforceは後者を狙った動きですわね

## MCPの弱点｜セキュリティはまだ発展途上

良い話ばかりではありませんわ。MCPは**AIに実際の操作権限を渡す**仕組みですから、事故が起きたときの被害も大きくなりますの。

- **なりすまし・悪意あるサーバー**：誰でもMCPサーバーを公開できるため、中身の怪しいサーバーをつなぐと情報が抜かれるおそれがある
- **プロンプトインジェクション**：AIが読み込んだ文書やメールに仕込まれた命令で、意図しない操作をさせられる
- **権限の渡しすぎ**：「全部の操作を許可」で接続すると、AIの誤解ひとつでデータが消える

2026年7月の新仕様ではOAuth 2.1／OpenID Connectに沿った認証の強化も入りましたが、企業が本格導入するには**権限管理や監査ログの仕組み**が別途必要ですわ。ここはサイバーセキュリティ企業やID管理企業にとっての商機でもありますの。

## よくある質問

**Q. MCPとは何の略ですか？**

Model Context Protocol（モデル・コンテキスト・プロトコル）の略ですわ。AIモデルに外部の「文脈（コンテキスト）」＝データや道具を渡すための「約束事（プロトコル）」という意味ですの。

**Q. MCPはAnthropicの独自規格ですか？**

もとはAnthropicが2024年11月に公開しましたが、2025年12月にLinux Foundation傘下のAgentic AI Foundationへ寄贈されましたわ。いまはOpenAI・Google・Microsoftなども支える中立の業界規格ですの。

**Q. 個人でもMCPを使えますか？**

使えますわ。Claude DesktopやClaude Code、Cursorなどに、公開されているMCPサーバーを設定すれば、AIからカレンダーやファイル、会計ソフトなどを操作できますの。ただし、信頼できる提供元のサーバーだけをつなぎ、渡す権限は最小限にしてくださいましね。

**Q. MCP関連銘柄というものはありますか？**

「MCP関連株」というくくりは、まだはっきりしたものはありませんわ。MCPは無料のオープン規格なので、**規格そのものでお金を稼ぐ会社はない**からですの。見るべきは、MCPでAIからつながれることで**利用が増えるデータを持つSaaS企業**と、MCPサーバーを動かす**クラウド基盤・セキュリティ企業**ですわ。

## まとめ｜MCPは「AIから選ばれるSaaS」への入場券

| 論点 | 要点 |
|------|------|
| MCPとは | AIが外部のアプリやデータを操作するための共通規格。「AIのUSB-C」 |
| 誕生 | 2024年11月25日、Anthropicがオープンソースで公開 |
| 普及 | OpenAI・Google・Microsoftなど主要AIが対応。2025年12月にLinux Foundation系の財団へ寄贈 |
| 最新動向 | 2026年7月28日の新仕様でステートレス化。大規模クラウド運用に対応 |
| SaaSへの影響 | 対応は「最低限の参加資格」。データの正本を持つ会社には追い風、画面の使いやすさが売りの会社には向かい風 |
| 投資家のチェック点 | AI経由の利用量の開示／座席以外の課金／自社エージェントの有無 |

MCPそのものは無料の配管にすぎませんわ。でも、その配管が通ったことで「**AIに選ばれるSaaS**」と「**AIに素通りされるSaaS**」の差が、これから決算の数字にじわじわ出てきますの。
