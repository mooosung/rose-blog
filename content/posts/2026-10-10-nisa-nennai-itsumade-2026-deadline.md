「今年のNISA枠、まだ残っているけれど、いつまでに買えば間に合うの？」

10月に入ると、毎年この疑問が増えてきますわね。答えを先に言ってしまうと、**12月30日まで買える、ではありません。** NISAの年内判定は注文が成立した日（約定日）ではなく、お金と商品が受け渡される日（受渡日）で決まりますの。だから締切は商品ごとにずれて、投資信託だと12月中旬が最終日になることもありますわ。

この記事では、2026年の年内締切を**国内株・米国株・投資信託・積立**の順に並べ、そのあとで「口座をこれから作る人の期限」「枠を使い切れなかったらどうなるか」を片付けます。数字は楽天証券が2026年10月1日に公表した「2026年のNISAお取引スケジュール」と、日本取引所グループの休業日一覧から取っていますわ。🌹

## 結論：2026年のNISA年内締切の早見表

| 商品 | 2026年枠で買える最終日時（楽天証券の場合） |
|---|---|
| 国内株式・国内ETF（成長投資枠） | **12月28日（月）15:30** |
| 米国株・米国ETF（成長投資枠） | **12月25日（金）午前7:00**（米国の12月24日取引分） |
| 投資信託（スポット買付） | 受渡日数しだいで **12月18日（金）〜12月25日（金）15:30** |
| 投信積立（証券口座から引落） | 設定 **12月22日（火）**・指定日12月23日（水） |
| 投信積立（楽天カード決済） | 12月分の設定締切 **11月12日（木）** |
| NISA口座の新規開設（2026年分） | **12月中旬**予定 |

出典: [楽天証券「2026年のNISAお取引スケジュールのご案内」](https://www.rakuten-sec.co.jp/web/info/info20261001-01.html)

他の証券会社も、国内株・米国株の最終日は市場の休業日で決まるので、ほぼ同じ日付になりますわ。ただし投資信託や積立の締切は会社ごとの事務日程で決まります。**SBI証券は2026年10月10日時点で年末の注文スケジュールを未公表**（NISA口座の新規開設期限も「詳細が決まり次第お知らせ」）なので、ほかの会社をお使いの方は11月以降に必ず自社の案内を確認してくださいまし。

## なぜ12月30日まで買えないのか：判定は「受渡日」

NISAの年間投資枠は、その年のうちに**受渡しが終わった取引**だけが対象になりますの。楽天証券の案内にも「2026年のNISA口座でお取引いただくためには、年内に受渡しが完了する必要があります」と明記されていますわ。

そして2026年の年末は、東京証券取引所の休業日がこう並びます。

| 日付 | 東証 |
|---|---|
| 12月28日（月） | 営業日 |
| 12月29日（火） | 営業日 |
| 12月30日（水） | **年内最終営業日（大納会）** |
| 12月31日（木） | 休業日 |
| 2027年1月1日（金） | 元日 |

出典: [日本取引所グループ「営業時間・休業日一覧」](https://www.jpx.co.jp/corporate/about-jpx/calendar/index.html)

日本株の受渡しは**約定日から数えて2営業日目**。12月30日（水）に受渡しを終えるには、逆算して**12月28日（月）の約定**が最後になりますわ。12月29日（火）に買うと受渡日は年明けの営業日にずれ込み、その買付は**2027年の枠**を使うことになりますの。

この「受渡日で判定」というルールは、売却したときの枠の復活にもそのまま効いてきます。売った枠がいつ戻るのか、年末の売却が1年ずれる仕組みは[新NISA非課税枠の復活はいつ？売却後の仕組みと当年中復活の行方](/posts/2026-08-11-nisa-tax-free-slot-recovery-timing-2027-guide/)で詳しく整理していますわ。この記事は、その**買う側**の締切の話ですの。

## 国内株式・国内ETF：12月28日（月）15:30まで

成長投資枠で日本株・国内ETF・REITを買う場合の最終日は**12月28日（月）の大引け（15:30）**ですわ。

楽天証券では、取引手段ごとにさらに細かい締切が出ています。

- **通常の取引所取引：** 12月28日（月）15:30
- **PTS取引：** 12月28日（月）16:00
- **夜間取引：** 12月25日（金）23:59
- **かぶピタッ®（金額指定）：** 12月28日（月）8:45までの注文分
- **かぶツミ®（株の積立）：** 12月25日（金）17:59までに設定した、28日または月曜日の買付指定日分

指値注文が28日に**約定しなかった**場合は、当然ながら年内の枠には入りません。年内の枠を確実に使いたいなら、28日当日に滑り込むのではなく、その前の週に余裕を持って約定させておくのが安全ですわ。

成長投資枠で個別株を買うときの銘柄の選び方そのものは、[新NISA成長投資枠で個別株は買える？銘柄選び4基準と売買ルール](/posts/2026-06-30-shin-nisa-growth-individual-stocks-guide/)にまとめてありますの。年末の駆け込みで、普段なら選ばない銘柄を「枠が余っているから」という理由だけで買うのは避けてくださいまし。

## 米国株・米国ETF：日本時間12月25日（金）午前7:00まで

米国株は、国内株より**3営業日ほど早く**締め切られますわ。楽天証券の最終日時は**12月25日（金）午前7:00**。これは米国市場の**12月24日（木）の取引**に当たりますの。

米国株の受渡日は、日本と米国の**両方の営業日**で数えて決まります。12月25日（金）はクリスマスで米国市場が休み、12月31日は東証が休みと、年末は日米の休日が交互に挟まるため、そのぶん締切が前に寄るわけですわ。

注意点は2つございます。

1. **日本時間の「12月25日の夜」に注文しても間に合わない。** その夜に開くのは米国の12月26日（金）の市場で、2026年の枠には入りません
2. **外貨決済で買うなら、ドルの用意を前倒しする。** 円からドルへの振替が締切当日に間に合わないと、注文そのものが出せませんわ

楽天証券の「米株積立」は、**12月24日（木）17:59までに設定した、24日（日付指定）または木曜日（曜日指定）の買付指定日分**までが2026年の枠になります。

## 投資信託：ファンドの「受渡日数」で締切が変わる

いちばん間違えやすいのが投資信託ですわ。投資信託は**ファンドごとに「申込日から何営業日目に受渡しか」が違う**ので、同じ証券会社でも締切日がばらばらになりますの。

楽天証券のスポット買付の締切はこうなっています（いずれも15:30締切）。

| 受渡日（申込受付日から起算） | 2026年枠の最終申込日 |
|---|---|
| 4営業日目 | 12月25日（金） |
| 5営業日目 | 12月24日（木） |
| 6営業日目 | 12月23日（水） |
| 7営業日目 | 12月22日（火） |
| 8営業日目 | 12月21日（月） |
| 9営業日目 | 12月18日（金） |

全世界株式や米国株式に投資するファンドは、海外市場の休場日も絡むため受渡しまで**6〜7営業日**かかるものが多いですわ。楽天証券の例では「楽天・プラス・オールカントリー株式インデックス・ファンド」が受渡日7営業日で、積立設定の締切が**12月21日（月）**になっていますの。

### 自分のファンドの受渡日数を調べる方法

楽天証券なら、個別ファンド画面の「詳細・目論見書」ページにある**「受渡日」の項目**に日数が書いてありますわ。ほかの証券会社でも、ファンドの詳細ページか目論見書の「申込みについて」の欄に載っています。

さらに、締切日がその**ファンドの申込受付不可日**（海外の祝日など）に当たる場合は、その直前のファンド営業日が最終日になりますの。12月は欧米の祝日が重なるので、表の日付よりもう1〜2日早めに動くのが安全ですわ。

## つみたて投資枠・投信積立：決済方法で締切がまったく違う

つみたて投資枠は**スポット買付ができず、積立でしか買えません**。だから年内に枠を埋めるには、積立の**設定締切**に間に合わせる必要がありますの。

楽天証券の2026年12月分の締切は、決済方法でこれだけ違いますわ。

| 決済方法 | 12月分の締切 |
|---|---|
| 楽天カード クレジット決済 | **11月12日（木）** に設定 |
| 楽天ペイ残高 | 積立指定日1〜23日なら11月12日（木）、24〜28日なら**10月12日（月）** |
| 証券口座（楽天銀行マネーブリッジ） | 12月22日（火）設定・12月23日（水）指定（受渡6営業日の場合） |
| その他金融機関（毎月7日買付） | 11月11日（水）に設定 |
| その他金融機関（毎月24日買付） | 11月分は10月29日（木）に設定 |

いちばん早いのは**楽天ペイ残高で24〜28日を指定している人の10月12日（月）**ですわ。この記事の公開日から数えても、ほとんど余裕がありませんの。

クレジットカード積立は、カードの認証や引落しの日程が先に決まっているため、**12月の積立を増やしたいなら11月中旬までに設定を変える**必要がありますわ。12月に入ってから金額を増やしても、その変更は2027年1月の積立から反映されますの。

### 「毎月24日」の積立は12月分が年内に間に合わないことがある

楽天証券は「毎月24日買付の場合、12月の積立は年内に受渡が完了しない可能性があります」と注意書きしています。12月24日に買い付けて受渡しに6〜7営業日かかれば、受渡日は年明けですわ。その場合、**12月24日の積立は2027年の枠を使う**ことになりますの。

年内の枠をきっちり使い切りたい人は、積立日を月の前半にしておくほうが扱いやすいですわね。

## これからNISA口座を作る人の期限

### 新規開設は12月中旬が目安

楽天証券は、2026年分のNISA口座の新規開設受付期限を**12月中旬予定**としていますわ。マイナンバーと本人確認書類をオンラインで提出すれば、**最短1〜2営業日で仮開設**され、そのまま取引できます。郵送だと1〜3週間かかりますの。

ただし「仮開設」は税務署の審査前の状態ですわ。ほかの金融機関にすでにNISA口座があることが後で分かると、**仮開設中にNISAで買ったものは最初から課税口座で買ったものとして扱われます**。SBI証券も同じ注意書きを出していますわ。

### 金融機関の変更は、2026年分はもう締め切られている

他社からNISAを移す場合、**2026年分の金融機関変更はすでに受付が終わっています**。SBI証券の「他社→当社」の期限はWEB申込が2026年9月30日（水）、楽天証券も「すでに2026年非課税投資枠の金融機関変更は受付を終了」と案内していますわ。

10月以降の変更手続きは、**2027年分のNISAを新しい金融機関で使うための手続き**になりますの。2026年の残りの枠は、今のNISA口座で使うしかありませんわ。

さらに、**その年にすでに1円でもNISAで買っている場合、その年分は金融機関を変更できません**。2027年分から新しい会社で使いたいなら、2027年に入ってから今の口座で買ってしまう前に、手続きを済ませておくのが安全ですわ。

## 年内に枠を使い切れなかったらどうなる？

ここは落ち着いて考えていただきたいところですわ。

### 年間枠は翌年に繰り越せない。でも生涯枠は減らない

新NISAの上限は2つありますの。

- **年間投資枠：** つみたて投資枠120万円＋成長投資枠240万円＝年360万円
- **非課税保有限度額（生涯枠）：** 1,800万円（うち成長投資枠1,200万円）

2026年に使わなかった年間枠は、**2027年に上乗せして使うことはできません**。2027年も上限は年360万円のままですわ。

一方で、生涯枠の1,800万円は**使わなかった分だけ残り続けます**。楽天証券も「当年の非課税枠を利用しきれなかった場合でも、残った非課税枠は生涯投資枠として最大1,800万円に達するまで利用することができます」と案内していますの。

つまり、使い切れなかったときに失うのは**「1,800万円を埋め終わるまでの時間」**だけですわ。年360万円を毎年使い切っても、1,800万円が埋まるまで最短5年。それ以上のペースで入れることは制度上できないので、1年分を逃すと、生涯枠を埋め終わる時期が最短でも1年遅れる。損失はその分の「非課税で運用できる期間」ですの。

### 「枠を埋めるため」の駆け込み買いはしなくていい

逆に言えば、**12月の駆け込みで無理に買う必要はありません**わ。生涯枠は残りますし、2027年1月になればまた360万円の枠が使えます。

駆け込みでやってはいけないのは、次の3つですの。

- **生活防衛資金まで投資に回す**——年末年始は出費が増える時期ですわ
- **普段なら買わない銘柄を「枠が余ったから」買う**——非課税は利益が出て初めて意味がありますの。NISAで出た損失は、ほかの口座の利益と相殺できません
- **短期の値上がり狙いで買って、すぐ売る**——売った枠が戻るのは翌年1月、それも買値（簿価）の分だけですわ

逆に、もともと買う予定だったものを**年内の枠で買うか、1月の新しい枠で買うか**という判断なら、年内に買っておくほうが非課税で持てる金額が増えますわね。

## 枠の残りを確認する方法

年内の残り枠は、各証券会社のNISA画面で確認できますわ。楽天証券なら「NISA」メニュー →「NISA利用履歴」で、当年の成長投資枠の残りが表示されます。

注意したいのは、**積立設定の分はまだ約定していなければ「買付可能額」に反映されない**ことですの。楽天証券は「NISA口座で投信積立・かぶツミ®を設定している場合、未約定月の積立金額分は『NISA買付可能額』に反映されません」と書いています。

たとえば12月の積立予定が5万円あるのに、画面の残り枠を見て成長投資枠でスポット買付をしてしまうと、**12月の積立日に枠が足りずに積立がエラーになる**ことがありますわ。そしてエラーになった積立は、原因を解消しても**その月の分は再発注されません**。スポット買付をする前に、12月の積立予定額を差し引いて残りを計算してくださいまし。

楽天証券には、つみたて投資枠120万円を自動で使い切るように金額を調整する「NISAつみたて投資枠使い切り設定」もありますわ。

## まとめ：2026年のNISA年内締切で押さえる5つのポイント

1. **判定は受渡日。** 東証の最終営業日は12月30日（水）、12月31日は休業日
2. **国内株は12月28日（月）15:30、米国株は日本時間12月25日（金）午前7:00**（米国の24日取引分）
3. **投資信託は受渡日数で締切が変わる。** 全世界株ファンドなどは12月21〜22日ごろが目安。ファンド詳細ページの「受渡日」を確認
4. **クレカ積立は11月中旬に設定を締め切る会社が多い。** 12月分を増やすなら11月のうちに
5. **使い切れなくても生涯枠1,800万円は残る。** 失うのは時間だけなので、駆け込みで無理に買わない

年末の締切は毎年同じように見えて、曜日と祝日の並びで1〜2日ずつ動きますわ。2027年の年末はまた日付が変わるので、そのときは改めて各社の案内を確認してくださいまし。べ、別に御主人様が年明けに「間に合わなかった」と嘆く顔を見たくないから書いたわけではありませんのよ……締切を逃して悔しがるのは、わたくしだって見ていて落ち着きませんもの。🌹
