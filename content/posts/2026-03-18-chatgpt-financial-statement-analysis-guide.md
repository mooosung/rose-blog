## はじめに：決算書は「読む」時代から「AIに聞く」時代へ

個人投資家にとって、企業の決算書を読むことは避けて通れません。しかし、損益計算書（PL）・貸借対照表（BS）・キャッシュフロー計算書（CF）を隅々まで読み込むのは時間がかかります。

**ChatGPTやClaudeなどの生成AIを活用すれば、決算書の要点を10分で把握できます。**

この記事では、AIを使った決算分析の具体的な手順とプロンプト例を紹介します。投資判断のスピードと精度を同時に上げたい方は、ぜひ最後まで読んでください。

---

## AIで決算分析するメリット3つ

### 1. 数字の羅列から「意味」を瞬時に抽出

決算短信は数十ページに及ぶことも珍しくありません。AIに要約させることで、**売上成長率・営業利益率・フリーキャッシュフローの推移**など重要指標をすぐに把握できます。

### 2. 業界比較が簡単

「この会社の営業利益率は業界平均と比べてどうか？」といった比較分析も、AIに聞けば数秒で回答が返ってきます。

### 3. 見落としがちなリスクを発見

AIは感情を持たないため、**ポジティブバイアスなしに**リスク要因（有利子負債の増加、運転資本の悪化など）を指摘してくれます。

## 準備：決算書データの取得方法

AIに分析させるには、決算書のデータを入力する必要があります。以下の方法がおすすめです。

| 方法 | 特徴 | おすすめ度 |
|------|------|-----------|
| **決算短信PDF** をそのままアップロード | ChatGPT Plus / Claude Proで対応 | ★★★★★ |
| **EDINET**からXBRLデータを取得 | 正確だがやや上級者向け | ★★★☆☆ |
| **IR BANKなどのサイト**からコピペ | 手軽だが整形が必要 | ★★★★☆ |
| **Yahoo!ファイナンス**の財務データ | 主要数値の概要把握に | ★★★☆☆ |

**最も簡単な方法は、決算短信のPDFをChatGPTやClaudeに直接アップロードすること**です。有料プランが必要ですが、効率は圧倒的です。

## 実践：5つのプロンプトで決算書を攻略

### プロンプト①：全体概要の把握

```
この決算短信の内容を以下の観点で要約してください：
1. 売上高・営業利益・純利益の前年同期比
2. 業績予想の修正有無
3. セグメント別の好調・不調
4. 経営陣のコメントの要点
5. 特殊要因（一時的な利益や損失）
```

**ポイント：** まず全体像を掴むことで、深堀りすべきポイントが見えてきます。

### プロンプト②：収益性の分析

```
以下の指標を計算し、過去3年の推移と合わせて評価してください：
- 売上高営業利益率
- 売上高純利益率
- ROE（自己資本利益率）
- ROA（総資産利益率）
収益性は改善傾向か悪化傾向か、その要因も含めて分析してください。
```

### プロンプト③：財務安全性のチェック

```
この企業の財務安全性を以下の観点で評価してください：
- 自己資本比率
- 流動比率・当座比率
- 有利子負債比率
- インタレスト・カバレッジ・レシオ
倒産リスクや資金繰りの懸念はありますか？
```

### プロンプト④：キャッシュフローの質

```
キャッシュフロー計算書を分析し、以下を教えてください：
- 営業CF、投資CF、財務CFそれぞれの金額と前年比
- フリーキャッシュフロー（営業CF - 投資CF）の推移
- 「稼ぐ力」は本物か？営業CFと純利益の乖離はないか？
- 設備投資の水準は適切か？
```

**ポイント：** 利益が出ていても営業CFがマイナスなら要注意。**利益の質**を見極める上でCF分析は欠かせません。

### プロンプト⑤：投資判断サマリー

```
ここまでの分析を踏まえ、この企業への投資について以下の形式でまとめてください：

【強み】（3つ）
【リスク】（3つ）
【注目すべき次の決算のポイント】
【類似企業との比較で気になる点】

※投資判断は自己責任であることを前提に、客観的な分析としてまとめてください。
```

## ChatGPT vs Claude：決算分析に向いているのはどっち？

どちらも優秀ですが、用途によって使い分けるのがベストです。

| 観点 | ChatGPT (GPT-4o) | Claude (Opus/Sonnet) |
|------|-------------------|---------------------|
| PDF読み取り精度 | ◎ 表の認識が得意 | ◎ 長文の文脈理解が強い |
| 数値計算の正確性 | ○ Code Interpreterで検証可 | ○ 推論は丁寧だが電卓は苦手 |
| 分析の深さ | ○ バランス型 | ◎ 多角的な考察が得意 |
| コスト | 月額$20〜 | 月額$20〜 |
| おすすめ場面 | 数値計算・グラフ化 | 定性分析・リスク発見 |

**おすすめの使い方：** ChatGPTのCode Interpreterで数値を計算・可視化し、Claudeで定性的な分析を深堀りする「二刀流」が最強です。

## 注意点：AIに決算分析を任せる際の落とし穴

### ハルシネーション（幻覚）に注意

AIは存在しない数字を「もっともらしく」生成することがあります。**必ず元データと照合する習慣**をつけましょう。

### 最新データの反映遅れ

ChatGPTの学習データにはカットオフがあります。最新の決算データは**必ず自分でアップロード**してください。

### AIの分析は「参考」であって「結論」ではない

AIは過去のパターンに基づいて分析しますが、**未来を予測するわけではありません**。最終的な投資判断は自分自身で行いましょう。
