## なぜ投資日記が資産形成を加速するのか

投資家として成長するうえで、**記録と振り返り**は欠かせませんわ。

- **感情的な売買の繰り返しを防ぐ**：「なぜあの時買ったのか」を記録しておくことで、同じミスを避けられる
- **投資哲学の言語化**：自分の判断軸を文章化することで、ブレない投資方針が固まる
- **パフォーマンス分析**：何が当たり、何が外れたかを定量的に把握できる

しかし従来の投資日記は「続けること」が最大の課題でしたわ。手書きや手動入力は面倒で、続かない。それをAIが解決しますのよ。

## NotionAIで実現できること

### 1. 売買メモの自動構造化

取引後に箇条書きでメモするだけで、NotionAIが整形してくれますわ。

**入力例（箇条書き）：**
```
NVIDIA 100株買い 約定値133ドル
理由：Blackwellの出荷加速、決算beat、RSI40台で押し目と判断
懸念：輸出規制リスク継続中
目標：180ドル（PER50倍想定）
損切ライン：115ドル割れ
```

**AI整形後：**

| 項目 | 内容 |
|------|------|
| 銘柄 | NVIDIA（NVDA） |
| 取引 | 100株購入 @ $133 |
| 根拠 | Blackwell出荷加速・決算beat・テクニカル割安 |
| リスク | 輸出規制継続リスク |
| 目標値 | $180（+35.3%） |
| 損切線 | $115（-13.5%） |

箇条書きを「表にして整理して」と一言AIに頼むだけ。これだけで記録の質が格段に上がりますわ。

### 2. 銘柄ページへのリンク＆AIサマリー

Notionでは銘柄ごとにページを作り、そこにAIサマリーを蓄積できますわ。

```
/AI ブロックを挿入 → 「このページの内容を3行で要約して」
```

複数の売買記録や決算メモが積み重なっても、AIが毎回要約してくれる。「NVIDIAについて自分はどんな見解を持っているか」を瞬時に把握できますの。

### 3. 感情ログの分析（これが一番重要）

投資日記の核心は**感情の記録**ですわ。

毎回の取引に「感情スコア」を付けることをおすすめしますの：
- **1〜3点**：不安・焦り・パニック売買
- **4〜6点**：中立・計画通り
- **7〜10点**：確信・強気・根拠あり

3ヶ月後にNotionAIに聞くのですわ：

> 「過去3ヶ月の売買記録を見て、感情スコアが1〜3のときと7〜10のときで、結果（損益）に差はありますか？」

感情的な売買がパフォーマンスに与える影響を**数値で**把握できる。これが行動改善の第一歩ですわ。

## 実践：NotionAI投資管理テンプレートの作り方

### データベース構成

```
📁 投資管理ハブ
├── 📊 ポートフォリオDB（銘柄×取得単価×評価額）
├── 📝 売買日記DB（日付×銘柄×取引内容×感情スコア）
├── 📰 銘柄研究DB（銘柄ページ×決算メモ×ニュース）
└── 📈 月次振り返りDB（月別パフォーマンス×反省点）
```

### 売買日記のプロパティ設定

| プロパティ | 種類 | 用途 |
|-----------|------|------|
| 日付 | Date | 取引日 |
| 銘柄 | Relation | 銘柄研究DBとリンク |
| 取引種別 | Select | 買い/売り/配当受取 |
| 金額（円） | Number | 取引額 |
| 感情スコア | Number | 1〜10点 |
| 根拠タグ | Multi-select | ファンダ/テクニカル/ニュース等 |
| 振り返り | Text | 結果の記録 |

### AIプロンプトを定型化する

Notionのテンプレートに、よく使うAIプロンプトを埋め込んでおくと便利ですわ。

**月次振り返りテンプレート内蔵プロンプト：**
```
今月の売買記録（上記）を分析して：
1. パフォーマンスが良かった取引の共通点
2. 損失が出た取引の共通点  
3. 来月改善すべき行動パターン
3点を箇条書きで教えて
```

月末にこれを実行するだけで、AIが客観的なフィードバックをくれますわ。

## 上級者向け：NotionAPIで自動化

プログラミングが少しできる方なら、**NotionAPI**を使って更に自動化できますわ。

```python
# 証券口座のCSVエクスポート → Notionへ自動インポート
import notion_client
import pandas as pd

# SBI証券のCSVを読み込み
df = pd.read_csv('sbi_trades.csv', encoding='shift-jis')

# Notionの売買日記DBに自動追加
client = notion_client.Client(auth="your_token")
for _, row in df.iterrows():
    client.pages.create(
        parent={"database_id": "your_db_id"},
        properties={
            "日付": {"date": {"start": row['約定日']}},
            "銘柄": {"title": [{"text": {"content": row['銘柄名']}}]},
            "金額": {"number": row['約定金額']}
        }
    )
```

月次で手動インポートするだけで、売買記録が自動でNotionに入りますわ。

## 続けるためのコツ3選

### 1. 完璧主義を捨てる

「全部書かなきゃ」と思うと続きませんわ。最低限の記録は：
- 銘柄名
- 買い/売り
- 感情スコア（1〜10の数字だけ）

この3つだけでも価値があります。AIが後で整理してくれますわ。

### 2. 取引直後の5分ルール

売買後5分以内にNotionを開いてメモする習慣を作ること。時間が経つほど感情の記憶は薄れますわ。

### 3. 月末の15分振り返り

月末にAIに全記録を要約させて、パターンを把握する。これだけで投資の質が確実に上がりますの。
