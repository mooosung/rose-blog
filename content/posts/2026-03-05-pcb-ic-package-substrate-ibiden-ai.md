## ICパッケージ基板とは？ひとことで言うと「チップとマザーボードの通訳」

**ICパッケージ基板**（IC Package Substrate、サブストレートとも呼びますわ）は、半導体チップ（ダイ）を上に載せ、下側でマザーボード（プリント基板）とつながる板ですの。

```
半導体チップ（ダイ）        … 配線はナノメートル単位
    ↕  バンプ（小さなはんだ）で接続
ICパッケージ基板            … ここで配線を段階的に太く・広くする
    ↕  はんだボールで接続
マザーボード（プリント基板）  … 端子はミリメートル単位
```

なぜ間に一枚挟む必要があるのか。理由は**大きさの落差**ですわ。

味の素グループはABFの解説ページで、この落差をこう説明しておりますの。CPUの内部回路は**ナノメートル**のサイズになっている一方、電子機器の中では**ミリメートル単位**の他の部品とつながなければならない。そのために「微細な電子回路を何層にも積み上げたビルドアップ基板」がCPUの土台として使われている——と。

チップの端子をそのままマザーボードにつなごうとしても、細かすぎて届きません。ICパッケージ基板は、チップ直下の細かい端子を受け止め、何層もの配線で**少しずつ間隔を広げながら**、下面の大きなはんだボールまで引き回しておりますの。だから「通訳」なのですわ。

### ICパッケージ基板の3つの役目

| 役目 | 中身 |
|------|------|
| ① 配線の引き回し | チップの数千〜数万本の端子を、マザーボードがつなげる間隔まで広げる |
| ② 電気を届ける | チップに大電流を安定して流す（電源の通り道） |
| ③ チップを守る・支える | 薄く割れやすいチップを物理的に支え、熱による反りを抑える |

AI半導体ではこの3つがすべて厳しくなりましたの。その話は後半の「AIで何が変わったか」でいたしますわ。

### プリント基板（PCB）との違い

「基板」と聞くと、パソコンの緑色のマザーボードを思い浮かべる方が多いと思いますわ。あれは**プリント基板**（PCB）で、ICパッケージ基板とは別物ですの。

| | プリント基板（マザーボード） | ICパッケージ基板 |
|---|---|---|
| 載せるもの | パッケージ済みの部品をたくさん | 半導体チップそのもの（1〜数個） |
| 大きさ | 数十cm角 | 数cm角（AI向けは10cm角に迫る大型品も） |
| 配線の細さ | 数十〜数百µm | 10µm前後、先端品はそれ以下 |
| 作り方 | 銅箔を溶かして配線を残す（サブトラクティブ法）が中心 | 銅を必要な場所にだけ足す（セミアディティブ法）が中心 |

配線の細さの目安を、メーカーの公開スペックで確かめておきますわね。TOPPANはFC-BGA基板の製品ページで、セミアディティブ法の配線幅／間隔を**10µm／10µm**、サブトラクティブ法を**30µm／30µm**、開発中の品で**7µm／7µm**と載せておりますの。イビデンも製品ページで、SAP（セミアディティブ・プロセス）を中心とした導体形成技術で「世界トップクラスの微細配線」を実現していると書いておりますわ。

## ABF基板とは？ICパッケージ基板の「高性能版」の呼び名

**ABF基板**とは、層と層のあいだの絶縁材に**ABF（Ajinomoto Build-up Film＝味の素ビルドアップフィルム）**を使ったICパッケージ基板のことですわ。業界での正式な呼び方は**FC-BGA基板**（Flip Chip Ball Grid Array）で、ABF基板はほぼ同じものを材料の名前で呼んだ通称ですの。

- **FC（フリップチップ）**：チップを裏返して、チップ面のバンプで基板に直接つなぐ方式
- **BGA（ボール・グリッド・アレイ）**：基板の裏面に、はんだボールを碁盤の目のように並べてマザーボードとつなぐ方式

### ABFは何をしているのか

ICパッケージ基板は、銅の配線層を何層も積み重ねた構造ですわ。上下の配線同士がくっつくとショートしてしまいますから、層と層のあいだに**絶縁材**を挟みますの。この絶縁材がABFですわ。

味の素グループの説明によれば、ABFはエポキシ樹脂・硬化剤・無機フィラー（微粒子）を独自に組み合わせた**熱硬化性のフィルム**で、1999年に大手半導体メーカーに採用されて以来、主要なパソコン向けCPUでは**ほぼ100%**のシェアに達しているそうですの。味の素の説明会資料でも「発売以来95%超のシェア」とされておりますわ。

ABFがここまで使われる理由は、**レーザーで小さな穴（ビア）を開けやすく、その表面に直接銅めっきで配線を作れる**からですの。液体のインクを塗っていた時代の絶縁材と違い、フィルムなので厚みが均一で、積み重ねやすいのですわ。

### ABF基板の断面構造

```
 ┌ ソルダーレジスト（表面保護）＋チップをつなぐバンプ
 ├ ビルドアップ層（ABF＋銅配線）× 数層   ← 上側の配線層
 ├ コア層（ガラス布入り樹脂の芯材＋貫通穴） ← 板の「芯」
 ├ ビルドアップ層（ABF＋銅配線）× 数層   ← 下側の配線層
 └ ソルダーレジスト＋はんだボール（マザーボードへ）
```

真ん中の**コア**が板の硬さを担い、その上下に**ビルドアップ層**を1層ずつ積んでいく。だから「ビルドアップ基板」とも呼ばれますの。AI向けの大型基板では、このビルドアップ層の数が増え続けておりますわ。

コアの材料はレゾナックなどが作っておりますわ。材料メーカー側の数字は[レゾナック（4004）株価分析](/posts/2026-10-05-resonac-4004-stock-semiconductor-materials/)で見ておりますの。

## ICパッケージ基板の種類：ABF・BT・セラミックの違い

ICパッケージ基板は1種類ではありませんの。チップの種類と求められる性能で、だいたい次のように使い分けられておりますわ。

| 種類 | 絶縁材・材料 | 主な用途 | 特徴 |
|------|------|------|------|
| **FC-BGA基板（ABF基板）** | ABF＋有機コア | CPU、GPU、AIアクセラレーター、サーバー・ネットワーク用ASIC | 端子数が多い高性能チップ向け。大型・多層 |
| **FC-CSP基板** | BT樹脂など | スマホのアプリケーションプロセッサーなど | 小型・薄型。チップとほぼ同じ大きさ |
| **ワイヤーボンディング用BGA／CSP基板** | BT樹脂など | メモリ、センサー、汎用IC | チップと基板を細い金属線でつなぐ従来方式 |
| **セラミックパッケージ** | セラミック | 光通信デバイス、車載・産業用など | 気密性・放熱・信頼性に強い |
| **次世代コア基板** | ガラスコア／セラミックコア | 超大型のAIチップ向け（開発・量産準備段階） | 芯材を硬い素材に替えて「反り」を抑える |

### ABF基板とBT基板の違い

検索でよく比べられるのがこの2つですわね。違いは**層間絶縁材と、載せるチップの規模**ですの。

- **ABF基板**：フィルムを積み重ねるビルドアップ構造で、細かい配線を何層も作れる。端子数が多く大きなチップ（CPU・GPU）向け
- **BT基板**：BT樹脂（ビスマレイミド・トリアジン樹脂）をガラス布にしみ込ませた材料を使う。寸法が安定していて薄く作りやすく、スマホ用チップやメモリ向けに多く使われる

ざっくり申し上げると、**「大きくて端子の多いチップはABF、小さく薄いチップはBT」**ですわ。AIブームで注目されているのは、もっぱらABFのほうですの。

### セラミックのパッケージ

京セラが得意とするのがセラミックですわ。樹脂の基板より高価ですけれど、湿気を通さず、熱に強いので、光通信用のデバイスなどに使われますの。京セラは2026年4月に、AIデータセンター向けの「多層セラミックコア基板」を開発中だと発表しておりますわ。決算の数字は[京セラ（6971）株価分析](/posts/2026-10-19-kyocera-6971-stock-ai-semiconductor-package/)にまとめましたの。

### ガラスコア基板

ABF基板の「芯」だけをガラスに替えるのが**ガラスコア基板**ですわ。上下の配線層には引き続きABFを使う設計が主流なので、「ガラスが出たらABFは終わり」ではありませんの。量産時期と関連6社は[ガラスコア基板とは？関連銘柄6社の量産時期](/posts/2026-10-12-glass-core-substrate-stocks-dnp-neg/)で整理しておりますわ。

## ABF基板の作り方：積んで、穴を開けて、銅を足す

ABF基板は、同じ工程を何度も繰り返して1層ずつ積み上げていきますの。おおまかな流れはこうですわ。

1. **コアを作る**：ガラス布入りの樹脂板（銅張積層板）にドリルで貫通穴を開け、銅めっきで表と裏をつなぐ
2. **ABFを貼る**：コアの上にABFフィルムを真空で貼り付け、熱で硬化させる
3. **レーザーで穴を開ける**：下の層とつなぐための小さな穴（**マイクロビア**）をレーザーで開ける
4. **銅の下地をつける**：穴の中と表面に、ごく薄い銅の膜をつける
5. **配線の型を作る**：感光性のレジストを貼り、配線にしたい部分だけ溝を残す
6. **銅を太らせる**：電気めっきで溝の部分にだけ銅を積む（ここが**セミアディティブ法**）
7. **型をはがす**：レジストと不要な下地の銅を取り除く → 1層完成
8. **2〜7を繰り返す**：必要な層数まで積む
9. **仕上げ**：表面をソルダーレジストで保護し、チップ側のバンプとはんだボールの土台を作る

イビデンが製品ページで技術の柱として挙げているのも、まさにこの**SAP（セミアディティブ・プロセス）による微細配線**と、**レーザー加工・めっきによるマイクロビア**ですの。

### なぜ作れる会社が限られるのか

工程の一つひとつは理屈で説明できますけれど、問題は**歩留まり**（良品率）ですわ。

10層を超える配線のどこか1か所でも断線やショートがあれば、その基板は不良品。しかもAI向けの基板は大きくなるほど、熱で反りやすく、1枚あたりの不良の確率も上がりますの。

さらにAI向けの基板は大型化が進んでおり、面積が広がるほど1枚の中に欠陥が入り込む確率も上がりますの。この歩留まりを上げられるノウハウこそが、参入障壁になっておりますわ。

## AIで何が変わったか：基板が大きく、厚く、足りなくなった

ここが、ICパッケージ基板が「AIのツルハシ」と呼ばれる理由ですわ。

### ① 基板がどんどん大きくなっている

AI半導体は、GPUのチップの周りにHBM（積み重ねたメモリ）を並べ、一つのパッケージにまとめる構造が主流ですの。載せるものが増えれば、土台の基板も大きくなりますわ。

台湾の基板最大手Unimicron（欣興電子）の簡（S.C. Chien）会長は、2026年10月20日の台湾の業界展示会（TPCA Show）で、AI向け基板の大きさを次のように説明したと報じられておりますの（TrendForce、2026年10月20日）。

| 時期 | 基板の大きさ（レチクル＝露光1回分の面積が基準） |
|------|------|
| 初期のAI向け | 約1倍 |
| 2025年 | 約3倍 |
| 2026年（目標） | 約5倍 |
| 2027〜2028年 | 5〜9倍 |
| 将来 | 12〜14倍に達する可能性 |

基板が大きくなるほど、反りを抑えるのが難しくなり、1枚あたりの歩留まりも下がりますわ。ガラスやセラミックのコアが研究されているのは、この反り対策ですの。

### ② 電流が桁違いに大きい

同じ発言の中で簡会長は、AIチップは**1,000アンペアを超える電流**を流すことがあると述べておりますわ。基板には、この大電流をむらなく安定して届ける「電源の通り道」の設計が求められますの。HBMとの高速な信号のやり取り、熱の逃がし方も同時に求められますわ。

HBMの仕組みについては[HBM（高帯域幅メモリ）とは？](/posts/2026-03-09-hbm-high-bandwidth-memory-ai-infrastructure-stocks/)で解説しておりますの。

### ③ 作る側が追いつかない

いちばん投資家の目を引くのはここですわね。簡会長は、

- 2028年までに、TSMCの先端パッケージ（CoWoS）の生産能力は2024年比**6.8倍**、大手クラウド企業の設備投資は**6.3倍**に増える見通しなのに対し、**ICパッケージ基板の生産能力は約2倍**にとどまる
- 主要装置の8割超で納期が延び、一部は**最大30か月**待ち
- 低熱膨張ガラスクロス、銅張積層板、**ABF**などの材料は特に逼迫しており、2027年には**約20%の供給不足**になりうる

と語ったと伝えられておりますの。ただし本人も、成長倍率の違いがそのまま供給不足を意味するわけではない（それぞれ元の生産能力の大きさが違う）と付け加えておりますわ。

それでも、**「チップは作れても、載せる基板と材料が足りない」**という構図が業界トップの口から出ている。これが、基板メーカーと材料メーカーに買いが集まった背景ですの。

## イビデンのICパッケージ基板：5,000億円で何を増やすのか

イビデン（岐阜県大垣市）は、株探の会社概要で「ICパッケージ、プリント配線板で首位級」と紹介されている、日本のICパッケージ基板の代表企業ですわ。製品ページでは用途として「パソコン・データセンター向けMPU、AI・車載向けGPU」を挙げておりますの。

### 設備投資計画（2026年2月3日のプレスリリース）

| 項目 | 内容 |
|------|------|
| 対象期間 | 2026年度〜2028年度の3か年 |
| 投資総額 | **約5,000億円**（電子事業） |
| 目的 | AIサーバー・高性能サーバー向けの高機能ICパッケージ基板の生産能力増強 |
| 第1フェーズ | 河間事業場（Cell6）中心に**約2,200億円**、2027年度から順次稼働 |

リリースには、河間事業場の工場棟は2023年度に竣工していたものの、量産は大野事業場を先に進めてきたこと、今回「顧客と方向性を合意し」量産に向けた投資を進めることが書かれておりますわ。建物はあったのに、顧客の確約を待っていた——ということですの。

なお日本経済新聞は2025年9月、イビデンが生成AI用の半導体基板の生産量を2027年に2.5倍へ引き上げると報じておりますわ。

### 業績と株価はこちらで

## 新光電気工業はいまどうなっている？

旧版のこの記事では「富士通の完全子会社になった」と書いておりましたけれど、**これは誤りでしたわ**。お詫びして訂正いたしますの。正しくは次のとおりですわ。

| 日付 | 出来事 |
|------|------|
| 2025年2月18日 | JICC-04株式会社が公開買付け（TOB）を開始。**買付価格5,920円** |
| 2025年3月18日 | 公開買付けが終了・成立 |
| 2025年5月20日 | 臨時株主総会で株式併合を承認 |
| **2025年6月6日** | **東証プライム市場で上場廃止** |

（出典：新光電気工業「上場廃止・株式併合等について」）

買い手のJICC-04は、官民ファンドの産業革新投資機構（JIC）傘下のJICキャピタルが運営するファンドの子会社ですわ。JICの発表によれば、JICC-04には**三井化学**と**大日本印刷（DNP）**も出資しておりますの。それまでの親会社だった富士通は、この取引で新光電気の株を手放した側ですわ。

つまり**新光電気工業の株はいま市場で買えません**。ICパッケージ基板の主要メーカーであることは変わりませんけれど、投資先としては、出資している三井化学・大日本印刷を通じて間接的に関わるしかありませんわ。DNPはガラスコア基板でも名前が挙がる会社ですの。

| 位置 | 主な会社（日本） | 特徴 |
|------|------|------|

味の素は、ABFを作る子会社の利益率が5割を超える一方、会社全体では食品が大半という「二つの顔」を持つ銘柄ですの。詳しくは[味の素（2802）株価分析](/posts/2026-09-28-ajinomoto-2802-abf-stock-analysis/)をご覧くださいまし。

### 知っておくべきリスク

- **設備投資の重さ**：基板メーカーは5,000億円規模の投資を先に払いますの。AIサーバー投資が一巡したとき、減価償却費という固定費は残りますわ
- **顧客の集中**：AI向け高機能基板は、ごく少数の大口顧客向けに作る製品ですの。1社の方針変更の影響が大きくなりますわ
- **技術の置き換え**：ガラスコアやセラミックコアが本格化したとき、どの会社がついていけるかは、まだ分かりませんの
- **期待の織り込み**：イビデンのPERは2026年10月2日時点で81.4倍（会社予想ベース）と、利益の伸びをかなり先まで織り込んだ水準ですわ。業績が良くても株価が下がることはありますの

## よくある疑問（FAQ）

**Q. ICパッケージ基板と半導体パッケージは何が違いますか？**

半導体パッケージは「チップ＋基板＋封止材など」をまとめた完成品の呼び名で、ICパッケージ基板はその中の**土台の部分**だけを指しますわ。家にたとえるなら、パッケージが家全体、基板が基礎ですの。

**Q. ABF基板とFC-BGA基板は同じものですか？**

ほぼ同じものを指しますわ。FC-BGAは**チップのつなぎ方**（フリップチップ）と**マザーボードへのつなぎ方**（ボール・グリッド・アレイ）からつけた名前、ABF基板は**絶縁材の名前**からつけた通称ですの。FC-BGA基板の絶縁材にはほぼABFが使われているので、同じ意味で使われておりますわ。

**Q. ABFの「A」は本当に味の素のAですか？**

はい、**Ajinomoto Build-up Film**の略ですわ。アミノ酸の研究から生まれたエポキシ樹脂の技術を応用して、味の素グループが1990年代に開発したものですの。

**Q. ABF基板の不足はいつまで続きますか？**

断言はできませんわ。Unimicronの会長は2027年に主要材料が約20%不足しうると述べておりますけれど、同時に「成長倍率の差がそのまま不足を意味するわけではない」とも言っておりますの。イビデンの新ラインが2027年度から順次稼働する予定であるなど、供給側も増強を進めておりますわ。

**Q. 新光電気工業の株を持っていたらどうなりましたか？**

TOBに応募していれば1株5,920円で売却、応募しなかった場合も株式併合の手続きで、TOB価格と同じ1株5,920円を基準に金銭が交付される仕組みでしたわ。受け取り手続きの詳細は、新光電気工業の「上場廃止・株式併合等について」のページで確認してくださいまし。

**Q. Unimicronなど台湾の基板メーカーの株は日本から買えますか？**

台湾株の個別銘柄を扱っている日本の証券会社は限られておりますわ。購入前に、お使いの証券会社の外国株の取扱国を確認してくださいまし。

## まとめ：基板は「チップの土台」であり、いちばん足りなくなりやすい部品

{{< roze-summary >}}
- **ICパッケージ基板**＝チップとマザーボードの間で、ナノ単位の配線をミリ単位へ広げ直す中間の基板
- **ABF基板**＝その高性能版。味の素のABFフィルムで層間を絶縁するビルドアップ基板で、正式にはFC-BGA基板
- 小型チップ・メモリは**BT基板**、気密性が要る部品は**セラミック**と使い分ける
- AI向けは基板が2025年の約3倍から2026年は約5倍のサイズへ。装置納期は最大30か月、2027年に材料が約2割不足しうると業界トップが警告
- 日本の代表は**イビデン**（3年で約5,000億円投資）。**新光電気工業は2025年6月に上場廃止**し、株では買えない 🌹
{{< /roze-summary >}}

AIの話題はどうしてもGPUそのものに集まりますけれど、そのGPUは**載せる板がなければ1個も出荷できません**の。チップより地味で、チップより増やしにくい——ICパッケージ基板は、そういう部品ですわ。
