「楽楽精算」のラクス（3923）の株価は、2026年10月14日の終値で**1,131円**。

株探に表示される予想PERは**15.9倍**ですわ。売上の8割以上をクラウドで稼ぎ、営業利益率が30%を超えるSaaS企業としては、ずいぶん安く見えますわね。

でも、この15.9倍をそのまま信じてはいけませんの。**今期の利益には、創業事業だったIT人材派遣を売った「一度きりの利益」約167億円が入っている**からですわ。

**[ラクス](https://www.rakus.co.jp/ir/)（証券コード：3923・東証プライム）** の株価がいま本当に割安なのか。この記事では、2026年8月14日に出た第1四半期決算と会社の説明資料をもとに、PERの「中身」を分解し、11月の第2四半期決算で何を確かめればいいのかまで整理いたしますわね🌹

## ラクスはどんな会社か｜中小企業向けクラウドの「楽楽」シリーズ

ラクスは、中小・中堅企業のバックオフィス業務をクラウドで支える会社ですわ。主力サービスはこちら。

- **楽楽精算**：経費精算システム。会社の看板商品ですの
- **楽楽明細**：請求書・納品書などの帳票を電子で発行するサービス
- **楽楽販売**：販売管理・案件管理をノーコードで作るデータベース
- **楽楽電子保存**：電子帳簿保存法に対応した書類保管
- **メールディーラー（楽楽自動応対）**：問い合わせメールの共有・管理
- **楽楽ビジネスカード**：2026年5月に提供を始めた法人カード

インボイス制度や改正電子帳簿保存法の対応需要を追い風に、長く高成長を続けてきた日本のSaaSの代表格ですわ。

そして2026年4月1日、会社の形が大きく変わりましたの。**創業事業だったIT人材派遣の子会社「ラクスパートナーズ」を、BREXA Technologyへ約187.7億円で譲渡**したのですわ。以後のラクスは「クラウド専業」になりました。

この売却が、決算の数字をとても読みにくくしていますの。順番にほどいていきますわね。

## 株価の現在地｜「SaaSの死」で721円まで売られ、そこから+56%

まずは株価の流れを、月末の終値で並べますわ。

| 時点 | 出来事 | 終値 |
|------|--------|------|
| 2025年9月末 | 高値圏 | 1,358円 |
| 2025年10月27日 | 52週高値（取引時間中1,329.5円） | — |
| 2025年12月末 | 2025年の大納会 | 1,040円 |
| 2026年3月23日 | 52週安値・年初来安値（取引時間中**721.9円**） | — |
| 2026年3月末 | 「SaaSの死」の売りが一巡 | 743.2円 |
| 2026年8月28日 | 年初来高値（取引時間中1,209円） | — |
| 2026年9月末 | 9月は−13.9% | 1,002円 |
| 2026年10月14日 | 直近 | **1,131円** |

2026年の1〜3月、ラクスは3か月連続で下げましたの。年末の1,040円から3月末の743円まで、**約−29%**ですわ。

原因はラクス個別の悪材料ではなく、「AIエージェントが業務ソフトの仕事を奪い、座席課金のSaaSは要らなくなる」という、いわゆる**「SaaSの死」論**でしたわ。日本株も米国株も、ソフトウェア銘柄がまとめて売られた時期ですの。この論そのものの是非は、[「SaaSの死」は本当か｜AIエージェント時代にソフトウェア銘柄を見極める3つのモノサシ](/posts/2026-09-17-saas-is-dead-ai-agent-software-stocks/)で詳しく検証していますわ。

そこから4月以降は持ち直して、10月14日の1,131円は**3月の安値から約+57%、年初から約+9%**。それでも52週高値の1,329.5円からは**約−15%**の位置ですわ。

テクニカル面では、10月14日時点で株価は**25日・75日・200日の移動平均をすべて上回って**います（株探調べで200日線から+19.15%）。下げ止まって上向きに戻している途中、という形ですの。

ひとつ気にしておきたいのは信用買い残ですわ。10月9日時点で買い残は約119万株、信用倍率は**7.25倍**。9月半ばの9.49倍からは下がりましたけれど、上値で売りたい人がまだ多く残っている形ですの。

## 数字①：予想PER15.9倍は「売却益込み」｜本業ベースでは約29倍

ここが今回いちばん大事なところですわ。

会社が出している2027年3月期（2026年4月〜2027年3月）の通期計画はこちら。

| 項目 | 2026年3月期（実績） | 2027年3月期（計画） | 前期比 |
|------|------------------|------------------|-------|
| 売上高 | 602.9億円 | **597.0億円** | −1.0% |
| うちクラウド事業 | 517.7億円 | 597.0億円 | **+15.3%** |
| うちIT人材事業 | 85.2億円 | — | 譲渡済み |
| 営業利益 | 173.5億円 | **205.0億円** | +18.2% |
| 営業利益率 | 28.8% | 34.3% | +5.6pt |
| 純利益 | 132.9億円 | **252.0億円** | +89.6% |
| EPS（1株利益） | 36.91円 | **71.16円** | +92.8% |
| 1株配当 | 7円 | 8円 | +1円 |

純利益が**+89.6%**と、ほぼ倍になっていますわね。予想PER15.9倍は、1,131円をこのEPS71.16円で割った数字ですの。

ところが、この純利益には**IT人材事業の譲渡に伴う特別利益 約167億円**（第1四半期に計上済み）が入っていますわ。来年以降はもう出てこない、一度きりの利益ですの。

そこで、本業の稼ぐ力だけで見直してみますわ。計算はあくまでわたくしの概算ですから、目安としてご覧になってくださいまし。

| ステップ | 数字 |
|---------|------|
| 計画営業利益 | 205.0億円 |
| 会社計画の法人税率（32.2%）を差し引く | 約139億円 |
| 発行済株式数（EPS計画から逆算で約3.54億株）で割る | **1株あたり約39円** |
| 株価1,131円 ÷ 約39円 | **PER 約29倍** |

**表示上の15.9倍ではなく、本業ベースでは30倍近い**、ということですわ。

さらに、第3四半期からは後で触れるプラスアルファ・コンサルティングの持分法適用で、**のれん相当額 約250億円の償却**（10〜20年で定額償却の想定。年12.5億〜25億円規模）が始まりますの。持分法の利益で一部は相殺されますけれど、純利益を少し押し下げる要因になりますわ。

では29倍は高いのか。売上が年15%前後伸び、営業利益率が30%台に乗った日本のSaaSとしては、**「割安」ではなく「成長がそのまま続く前提の、ほどほどの値段」**というのがわたくしの見立てですわ。PBRも10.44倍、PSRは6.71倍（いずれも10月14日・株探）ですから、資産の裏付けで買う株ではありませんの。

## 数字②：クラウド事業の売上 +17.8%｜「売上微増」は見かけだけ

次は、第1四半期（2026年4〜6月）の実績ですわ。

| 項目 | 2026年3月期 1Q | 2027年3月期 1Q | 前年同期比 |
|------|--------------|--------------|-----------|
| 連結売上高 | 140.8億円 | **142.1億円** | +0.9% |
| うちクラウド事業 | 120.7億円 | 142.1億円 | **+17.8%** |
| うちIT人材事業 | 20.2億円 | — | — |
| 売上総利益率 | 75.1% | **81.6%** | +6.4pt |
| 営業利益 | 36.6億円 | **47.6億円** | +30.1% |
| 営業利益率 | 26.0% | **33.5%** | +7.5pt |
| 純利益 | 35.4億円 | 146.3億円 | +313.6% |
| 従業員数 | 3,201名 | 2,396名 | −25.1% |

連結の売上は**+0.9%**しか伸びていませんわ。株探の見出しだけ見ると「成長が止まった？」と驚くかもしれませんけれど、これは前年にあったIT人材事業の約20億円が丸ごと抜けたからですの。

**クラウド事業だけで比べると+17.8%**。こちらが本当の成長率ですわ。

そして見てほしいのは利益率ですの。原価のかかる人材派遣がなくなったことで、売上総利益率は75.1%→**81.6%**へ。営業利益率は**33.5%で過去最高**ですわ。会社資料によれば、クラウド事業の営業利益率は前四半期比で**5四半期連続の改善**ですの。

通期計画に対する進捗も確認しておきますわ。経常利益の進捗率は**23.8%**で、過去5年平均の22.6%とほぼ同じ。会社自身も「社内計画を上回る順調な立ち上がり」と説明していますわ。

利益率改善のもうひとつの理由は、**広告宣伝費の絞り込み**ですの。会社資料でも、売上高に占める人件費率・広告宣伝費率はともに「低下傾向が継続」と説明されていて、今期も広告宣伝費は「一段と効率化を進める」方針ですわ。テレビCMで顧客を取りに行く段階から、既存顧客に機能を足して単価を上げる段階へ移ってきた、ということですわね。

## 数字③：投資計画 約322億円｜売却で得たお金の「行き先」

IT人材事業の売却で、4月1日時点の現預金は**313億円**まで膨らみましたの。ラクスはこのお金を、配当ではなく**他社への出資**に回し始めていますわ。

| 投資先 | 内容 | 金額 |
|-------|------|------|
| プラスアルファ・コンサルティング（4071） | 7月までに段階取得 76.6万株 | 約20億円 |
| 同上 | 8月21日に追加取得 690.6万株（1株3,350円）→ 議決権**22.21%**で持分法適用会社に | **約231億円** |
| ROBOT PAYMENT（4374） | 資本業務提携・12万株（議決権3.10%） | 約3億円 |
| フリー（4478・freee） | 6月末までに段階取得 295万株（議決権**4.95%**） | 約68億円 |

**合計で約322億円**ですわ。第2四半期には借入も行う予定ですけれど、会社は「**エクイティファイナンス（増資）の予定はなし**」と明言していますの。

狙いはそれぞれこう読めますわ。

- **プラスアルファ・コンサルティング**：タレントマネジメントの「タレントパレット」の会社ですわ。2026年4月から共同で「楽楽人事労務」を売り始めていて、経費・請求の「楽楽」に、人事の領域を足す動きですの
- **ROBOT PAYMENT**：「請求管理ロボ」の一部機能をOEMで受け、「楽楽債権管理」を作り直す予定（2026年12月以降）ですわ
- **freee**：同じ中小企業向けクラウドの競合でもある会社に約5%出資。開示基準には当たらないものの、会社が自ら「投資判断に資する情報」として開示していますの

投資家として気にすべき点は2つですわ。

1. **お金を「株主還元」より「出資」に先に使った**こと。期初時点の総還元性向は11.2%で、会社方針の「20%以上」に届いていませんの。会社は追加還元を「引き続き検討中」としていますわ
2. **持分法の会計処理**。プラスアルファ社の利益の22%分が営業外に入る一方、のれん相当額の償却がずっと続きますの。本業の営業利益には出てこない部分なので、純利益で見るときは注意が要りますわ

## 数字④：AI戦略｜「入力を最大90%削減」は課金につながるか

「SaaSの死」の不安に、ラクスは2026年6月15日の**AI戦略**で答えましたの。2030年までに、人は最終確認をするだけで業務が進む「完全自動化」を目指す、という内容ですわ。

ロードマップは3段階ですの。

| フェーズ | 時期 | 中身（楽楽精算の例） |
|---------|------|------------------|
| Phase 1 | 2025〜2026 | **伝票作成AIエージェント**：領収書やカード明細から申請を自動作成 |
| Phase 2 | 2026〜2027 | 適格請求書チェックAI、申請レビューAI、証憑取得AIエージェント |
| Phase 3 | 2027〜2029 | 証憑と伝票の自動照合 → 人は最終確認だけ |

すでに動いているのが「伝票作成AIエージェント」ですわ。2026年6月16日から提供されていて、**30ユーザーで月5,000円から**の有料オプションですの。会社の試算では、申請者の入力作業を**最大90%削減**できるそうですわ。

7月16日からは、法人カード「楽楽ビジネスカード」の利用明細を、このAIエージェントが拾って精算伝票を自動で作る連携も始まりましたの。

ここが投資の観点で大事なところですわ。「SaaSの死」論の核心は、**AIが仕事をするほど人の数（座席）が減り、座席課金の売上も減る**という心配でしたわね。ラクスのAI機能は、座席課金の上に**別料金のオプションとして乗せる**形ですの。AIを「売上を減らすもの」ではなく「単価を上げるもの」にできるかどうか。これが、今後の決算で確かめていくべき一番の論点ですわ。

## 数字⑤：配当利回り0.71%｜15期連続増配だが「配当株」ではない

ラクスは**累進配当**（前年を下回らない配当）を方針にしていて、今期の計画は年8円。**15期連続の増配**になる予定ですわ。

ただし10月14日の株価1,131円で割った利回りは**0.71%**。配当性向も11.2%と低く、配当を目当てに買う株ではありませんの。あくまで成長株として、利益とキャッシュの伸びで評価する銘柄ですわ。

追加還元（自社株買いなど）が出てくるかどうかは、今期の見どころのひとつですわね。会社は「資金需要見合いで機動的に判断」としていますの。

## 11月の第2四半期決算で見るべき3つのポイント

ラクスの第2四半期決算は、例年11月中旬に出ますわ（前年は2025年11月14日）。そこで確かめたいのは次の3つですの。

**1. クラウド事業の成長率が+15%台を保てるか**

1Qは+17.8%でしたわ。通期計画の+15.3%を上回るペースが続くかどうか。ここが落ちると、本業ベースPER約29倍の前提が崩れますの。

**2. AIオプションの導入状況が数字で語られるか**

伝票作成AIエージェントが何社に入ったのか、単価がどれだけ上がったのか。会社が具体的な数字を出してくるかどうかは、「SaaSの死」論への一番わかりやすい回答になりますわ。

**3. 通期計画の修正と追加還元**

会社は1Q時点で「業績見通しは精査中、現時点で修正はなし」「追加還元策は引き続き検討中」としていますの。借入とのれん償却を織り込んだ計画修正、そして自社株買いなどの追加還元が示されるかに注目ですわ。

## まとめ｜表示PERは安く見えるが、本業は「成長の続き」に値段が付いている

| 論点 | 現状 |
|------|------|
| 株価 | **1,131円**（2026年10月14日終値）。3月の安値721.9円から約+57%、52週高値から約−15% |
| 予想PER（表示） | **15.9倍**（売却益 約167億円込み） |
| 予想PER（本業ベース・概算） | **約29倍**（営業利益205億円・税率32.2%で試算） |
| 1Q決算 | クラウド売上**+17.8%**、営業利益率**33.5%**で過去最高 |
| 通期計画 | 売上597億円（クラウド+15.3%）、営業利益205億円（+18.2%） |
| 投資 | 約322億円（プラスアルファ社・freee・ROBOT PAYMENT）、増資の予定なし |
| AI | 伝票作成AIエージェント（30ユーザー月5,000円〜）を有料オプションで提供 |
| 配当 | 年8円・利回り**0.71%**・15期連続増配予定 |
| 次の決算 | 2Q決算は例年11月中旬 |

ラクスの株価を一言でまとめるなら、**「表示PERは安く見えるけれど、中身は成長がそのまま続くことに値段が付いた株」**ですわ。売却益を除けば本業ベースのPERは30倍近く。クラウド事業は年15〜18%で伸び、利益率は過去最高を更新し続けていますの。

ふん、べ、別に「PER15倍台だから割安ですわ」なんて申し上げるつもりはありませんのよ。その数字には一度きりの売却益が入っている、というだけですわ。見るべきなのはクラウド事業の成長率と、AIオプションが単価を押し上げられるかどうか。11月の決算で、この2つは確かめられますの。
