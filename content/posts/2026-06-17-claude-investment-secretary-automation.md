個人投資家の最大の悩みのひとつが**情報過多と時間不足**ですわ。決算シーズンには数十社の決算を追い、毎日無数のニュースが流れ込んでくる。それを全部読んでいたら、本業も生活も立ち行かなくなりますわよね。

そこで活躍するのが、AIを「投資家の秘書」として使う仕組み作りですわ。今回は[Claude](https://www.anthropic.com/claude)・[ChatGPT](https://chatgpt.com/)を使って、銘柄ウォッチと決算サマリーをほぼ自動化する実践的な方法をお伝えしますわ。

## なぜAIが投資リサーチを変えるのか

従来の投資リサーチは**人間がやるには非効率な作業**に満ちていますわ。

- 決算プレスリリース（英語30〜50ページ）を読む
- アナリストレポートから要点を抜き出す
- 四半期ごとの数字変化を比較する
- 各社のガイダンス（業績予想）を整理する

これらはすべて「情報を構造化して要約する」タスクで、AIが最も得意とする分野ですわ。人間は判断（買うか売るか）に集中し、情報整理はAIに任せる。この分業が投資効率を劇的に高めますのよ。

## STEP 1：銘柄ウォッチリストのAI管理

まず基盤となる**銘柄ウォッチリスト**をAIと一緒に整備しますわ。

### Claudeへの初期プロンプト

```
あなたは私の個人投資秘書です。以下の銘柄リストを管理し、
毎月更新できるよう構造化してください。

【ウォッチリスト】
- NVIDIA (NVDA)：AIチップ主力、半導体セクター
- Microsoft (MSFT)：クラウド+AI、防御的成長株
- テスラ (TSLA)：EV＋エネルギー、高ボラティリティ
- トヨタ (7203)：日本自動車、割安感あり

各銘柄について以下を表形式でまとめてください：
1. 業種・セクター
2. 私が保有している理由（仮説）
3. 次に確認すべき決算日
4. 重要な監視指標（KPI）
5. 売却を検討すべき条件
```

このプロンプトをベースに会話を続けることで、AIが自分専用の銘柄データベースを構築してくれますわ。

### 更新の仕組み

毎月第1週に以下のプロンプトでリストを更新しますわ。

```
先月のウォッチリストに以下の変化がありました：
- MSTFが決算でクラウド売上+22%、ガイダンス上方修正
- TSLAが3Qに工場新設発表
- 新規追加候補：Broadcom (AVGO)

これらを反映して、ウォッチリストを更新してください。
各銘柄の「保有仮説が維持されているか」も確認してください。
```

## STEP 2：決算サマリー自動生成

決算リサーチで最も時間がかかるのが**英文IR資料の読み込み**ですわ。ここをAIで自動化します。

### 基本フロー

```
1. 決算プレスリリースのURLをコピー
2. Claudeに貼り付けてサマリーを依頼
3. 5分で決算の要点を把握
```

### 決算サマリー用プロンプトテンプレート

```
以下の決算プレスリリースを読んで、個人投資家向けに要約してください。

URL（またはテキスト貼り付け）：[決算資料URL]

以下の形式でまとめてください：

## 決算サマリー：[銘柄名] [四半期]

### ✅ 3つのポジティブ
1. 
2. 
3. 

### ⚠️ 3つの懸念点
1. 
2. 
3. 

### 📊 主要数字
- 売上高：前年比 %（予想比 %）
- EPS：前年比 %（予想比 %）
- 来期ガイダンス：

### 🎯 保有継続・売却の判断軸
長期保有を続けるべき理由：
売却を検討すべき条件：

### 💬 経営陣コメントで注目すべき発言
```

このテンプレートを使うと、英語が苦手でも決算の全体像を5〜10分で把握できますわ。

## STEP 3：ニュースフィルタリングの仕組み

毎日流れる無数のニュースから**自分に関係するものだけを抽出**する仕組みを作りますわ。

### デイリーニュース整理プロンプト

```
今日の金融ニュース（以下に貼り付け）を読んで、
私のポートフォリオへの影響を評価してください。

【私のポートフォリオ】
NVDA、MSFT、TSLA、7203（トヨタ）

【今日のニュース】
（RSSフィードやNewsPicks等からコピペ）

影響が高い：🔴
影響が中程度：🟡
影響なし：⚪

各ニュースについて、保有銘柄への具体的な影響を1〜2行で説明してください。
```

### Google アラートとの組み合わせ

1. Googleアラートで各銘柄名を登録（例：「NVDA OR NVIDIA 決算 OR earnings」）
2. メールに届いたアラートをまとめてClaudeに投げる
3. 重要度フィルタリングをAIに任せる

これだけで、毎日のニュース整理が**30分→5分**に短縮できますわ。

## STEP 4：四半期レビューの自動化

3ヶ月ごとに行うポートフォリオ見直しも、AIで効率化できますわ。

### 四半期レビュー用プロンプト

```
今四半期のポートフォリオレビューをお願いします。

【保有銘柄と変化】
- NVDA：+15%（AI需要拡大、競合AMD追い上げ）
- MSFT：+8%（Azure好調、OpenAI投資回収期待）
- TSLA：-12%（価格競争激化、中国EV台頭）
- 7203：+5%（円安効果、北米販売好調）

【当初の投資仮説】（3ヶ月前に設定）
...

以下を評価してください：
1. 各銘柄で当初仮説は維持されているか？
2. 仮説が崩れた銘柄はどれか？
3. リバランスが必要な理由があるか？
4. 来四半期の注目イベントは何か？
```

## STEP 5：Notionとの連携でシステムを完成させる

Claudeで生成したサマリーをNotion に蓄積すると、**長期的な投資ジャーナル**として機能しますわ。

### Notion銘柄データベースの構造

```
📊 投資ジャーナル（Notion DB）
├── 銘柄ごとのページ
│   ├── 基本情報（セクター、購入理由）
│   ├── 決算サマリー（四半期ごと）
│   ├── ニュースクリッピング
│   └── 売却基準
└── 月次振り返りページ
    ├── AIが生成したサマリー
    └── 自分の判断メモ
```

Claudeで生成したテキストを Notionにコピーして整理するだけで、**自分だけの投資リサーチデータベース**が完成しますわ。

## AIを使う際の注意点

便利なAI活用ですが、いくつか気をつけるべきことがありますわ。

### ⚠️ 情報の新鮮度を確認する

ClaudeやChatGPTは**学習データのカットオフ日以降の情報**を知りません。決算数字など最新データは、必ず自分でIR資料や金融サイトから取得してAIに入力する必要がありますわ。

### ⚠️ 投資判断は自分で行う

AIはあくまで情報整理の補助役ですわ。「AIがXXと言ったから買う」という判断は危険ですの。最終的な売買の判断は、AIの出力を参考にしつつ自分で行うことが大切ですわよ。

### ⚠️ 機密情報を入力しない

証券口座の口座番号や残高などの機密情報はAIに入力しないよう注意してくださいませ。

## まとめ：AIで投資の「時間コスト」を下げる

| タスク | 従来の時間 | AI活用後 |
|--------|-----------|---------|
| 決算資料読み込み | 1〜2時間 | 10〜15分 |
| 日次ニュース整理 | 30分 | 5分 |
| 四半期レビュー | 2〜3時間 | 30〜45分 |
| ウォッチリスト更新 | 1時間 | 15分 |

AIを「投資家の秘書」として使いこなすことで、**情報収集・整理の時間を70〜80%削減**できますわ。浮いた時間を投資判断の質を高めることに使えば、長期的なリターン向上にもつながりますのよ。

難しいプログラミングは不要。Claude・ChatGPTに上手くプロンプトを渡すだけで、個人投資家でもプロ級の情報整理が実現できますわ。ぜひ試してみてくださいませ🌹
