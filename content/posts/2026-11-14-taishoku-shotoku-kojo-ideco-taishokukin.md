「iDeCoは受け取るときも税金が優遇される、って聞いたけれど、具体的にいくらまで非課税なの？」
「会社の退職金もあるのに、iDeCoの控除って本当に別枠で使えるの？」

答えの鍵は、**退職所得控除**という1つの言葉ですわ 🌹

先に結論を言っておきますわね。

- 退職所得控除は、**退職金やiDeCoの一時金から差し引ける非課税枠**。iDeCoでは**掛金を出していた年数**が勤続年数の代わりになる
- 加入20年で800万円、30年で1,500万円まで、iDeCoの一時金に税金はかからない
- ただし**会社の退職金と同じ年なら控除は1回分**。別の年にずらしても、期間が近いと**重なった年数分の控除が削られる**

この記事は「受け取るときの税金の計算」だけに絞りますの。一時金・年金・併用のどれを選ぶかは[iDeCo受け取り方はどれが一番お得？一時金・年金・併用の判定表](/posts/2026-06-16-ideco-payout-strategy-tax-optimization/)で判定表にしていますから、計算の中身を知ってから戻ってくると判断がぶれませんわ。

## 退職所得控除とは｜iDeCoでは「加入年数」が勤続年数になる

退職所得控除は、退職金のように「長年働いた結果としてまとめて受け取るお金」の税金を軽くするための控除ですわ。[国税庁 No.1420](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm)は、確定拠出年金（iDeCo・企業型DC）の老齢給付金を一時金で受け取った場合も**退職所得とみなす**と定めていますの。

計算式は次のとおりですわ。

| 勤続年数（A） | 退職所得控除額 |
|---|---|
| 20年以下 | 40万円 × A（80万円に満たない場合は80万円） |
| 20年超 | 800万円 ＋ 70万円 ×（A − 20年） |

そして退職所得の金額は、

**（受け取った額 − 退職所得控除額）× 1/2 ＝ 退職所得**

控除を超えた部分も半分にしか課税されず、給与など他の所得と合算しない**分離課税**ですの。iDeCoの一時金がそのまま給与に上乗せされて税率が跳ね上がる、ということはありませんわ。

iDeCoで押さえておくべき「数え方」のルールは3つですの。

1. **勤続年数＝掛金を出していた期間（加入者期間）**。1年未満の端数は1年に切り上げる（10年2か月なら11年）
2. **掛金を止めていた期間（運用指図者の期間）は数えない**。詳しくは[iDeCoの運用指図者とは｜掛金を止めると退職所得控除が増えない理由](/posts/2026-10-24-ideco-unyou-sashizusha-guide/)にまとめましたわ
3. **最低でも80万円**。加入1年でも2年でも、控除は80万円から始まりますの

## 控除オーバーの目安｜加入年数別の早見表

「自分のiDeCoは控除に収まるのか、はみ出すのか」。これがわかれば、受け取り方の8割は決まりますわ。まず加入年数ごとの控除額ですの。

| 加入年数 | 退職所得控除額 |
|---|---|
| 5年 | 200万円 |
| 10年 | 400万円 |
| 15年 | 600万円 |
| 20年 | 800万円 |
| 25年 | 1,150万円 |
| 30年 | 1,500万円 |
| 35年 | 1,850万円 |
| 40年 | 2,200万円 |

次に、毎月の掛金と運用利回りから**受け取り時の残高の目安**を出して並べてみますわ（毎年末に1年分を積み立てたと仮定した概算。手数料・税金は考えていませんの）。

| 掛金（月額） | 加入年数 | 利回り3%の残高 | 利回り5%の残高 | 控除額 | 判定 |
|---|---|---|---|---|---|
| 2.3万円（会社員・企業年金なし） | 20年 | 約742万円 | 約913万円 | 800万円 | 3%なら収まる／5%だとオーバー |
| 2.3万円（同上） | 30年 | 約1,313万円 | 約1,834万円 | 1,500万円 | 3%なら収まる／5%だとオーバー |
| 6.8万円（自営業の上限） | 20年 | 約2,193万円 | 約2,698万円 | 800万円 | **大きくオーバー** |
| 1.2万円（少額で積み立てる例） | 20年 | 約387万円 | 約476万円 | 800万円 | 余裕で収まる |

ここから見える目安は2つですわ。

- **会社員で退職金がない人**は、利回り次第で控除ぎりぎり。はみ出した分だけ年金で受け取る「併用」が候補になりますの
- **自営業で上限まで出している人**は、控除を大きく超えます。超えた部分は1/2課税とはいえ、全額一時金にすると税率が上がっていくので、年金や併用で分ける意味が大きいのですわ

2027年1月からは掛金の上限が引き上げられ（会社員で企業年金なしなら月6.2万円）、残高が控除を超える人は確実に増えますの。上限の変更点は[iDeCo掛金上限が2027年1月から激変](/posts/2026-08-18-ideco-2027-contribution-limit-reform-guide/)をどうぞ。

ただし、この早見表は**会社の退職金がない場合**の話ですの。退職金がある人は、次の節からが本番ですわ。

## 退職金とiDeCo一時金を同じ年に受け取ると控除は1回分

同じ年に2か所以上から退職所得を受け取ると、[国税庁 No.2735](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2735.htm)のとおり**金額を合計し、勤続年数は最も長い期間を軸に、重ならない部分だけを足して**計算しますの。

会社員のiDeCo加入期間は、ほとんどが会社の勤続期間の内側に収まっていますわね。つまり**iDeCoの加入年数は1年も上乗せされない**のですわ。

### 計算例1：60歳で退職金1,800万円とiDeCo600万円を同じ年に受け取る

- 会社：25歳〜60歳の勤続35年、退職金1,800万円
- iDeCo：45歳〜60歳の加入15年、一時金600万円

| 項目 | 計算 |
|---|---|
| 勤続年数 | iDeCoの15年は会社の35年の中に収まる → **35年** |
| 退職所得控除 | 800万円＋70万円×（35−20）＝**1,850万円** |
| 収入の合計 | 1,800万円＋600万円＝2,400万円 |
| 退職所得 | （2,400万円−1,850万円）×1/2＝**275万円** |
| 所得税（復興特別所得税込み） | （275万円×10%−97,500円）×102.1%＝**約18.1万円** |
| 住民税 | 275万円×10%＝**27.5万円** |
| **税金の合計** | **約45.6万円** |

退職金1,800万円だけなら控除1,850万円の内側で**税金は0円**でしたの。つまり、**iDeCoの600万円を同じ年に一時金で受け取ったことで、約45.6万円の税金が新しく発生した**のと同じですわ。

これが「退職金がある人は、iDeCoは年金で受け取ったほうがいい」と言われる理由ですの。所得税の税率は[退職所得の源泉徴収税額の速算表](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2732_besshi.htm)によりますわ。

## 別の年でも控除が削られる「重複期間」の計算

「じゃあ年をずらせばいいのね」——そう考える方は多いのですけれど、ここに落とし穴がありますわ。

[国税庁 No.2732](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2732.htm)では、前の年以前に退職所得を受け取っていて、その期間と今回の期間が重なっている場合、**今回の控除額から「重なった年数分の控除額」を差し引く**と定めていますの。調整の対象になる範囲は、受け取る順番で変わりますわ。

| 受け取る順番 | 調整の対象 |
|---|---|
| iDeCo一時金が先 → 退職金が後 | 退職金を受け取る年の**前年以前9年内**にiDeCo一時金を受け取っていれば調整（**2026年1月1日以後**に受け取るiDeCo一時金から。それより前は4年） |
| 退職金が先 → iDeCo一時金が後 | iDeCo一時金を受け取る年の**前年以前19年内**に退職金を受け取っていれば調整 |

計算の手順は次の3ステップですの。

1. 今回の受け取り分だけで、ふつうに控除額を計算する
2. 前回と今回で**重なっている年数**（1年未満は切り捨て）を数え、その年数で控除額を計算する
3. 1から2を引いた残りが、今回の控除額（80万円未満なら80万円）

もう1つ細かいルールがありますわ。**前回受け取った額が、前回の控除額より少なかった場合**は、前回の期間を「控除を使い切った分の年数」に縮めてから重なりを数えますの（受取額÷40万円、800万円超なら（受取額−800万円）÷70万円＋20年。1未満切り捨て）。控除を使い残した分は、ちゃんと後に回せる仕組みですわ。

### 計算例2：60歳でiDeCo500万円、65歳で退職金2,300万円（iDeCoが先）

- iDeCo：45歳〜60歳の加入15年、60歳で一時金500万円 → 控除600万円の内側なので**0円**
- 会社：22歳〜65歳の勤続43年、65歳で退職金2,300万円

| 項目 | 計算 |
|---|---|
| ふつうの控除額 | 800万円＋70万円×（43−20）＝2,410万円 |
| 前回（iDeCo）の期間の縮め方 | 500万円＜600万円なので、500万円÷40万円＝12.5 → **12年**（45歳〜57歳）とみなす |
| 重複期間 | 会社の勤続期間と12年が丸ごと重なる → **12年** |
| 差し引く額 | 40万円×12年＝480万円 |
| 今回の控除額 | 2,410万円−480万円＝**1,930万円** |
| 退職所得 | （2,300万円−1,930万円）×1/2＝185万円 |
| 税金の合計 | 所得税 約9.4万円＋住民税18.5万円＝**約27.9万円** |

2025年までにiDeCo一時金を受け取っていれば、調整されるのは「前年以前4年内」だけ。5年空いていれば調整なしで、退職金にも2,410万円の控除がまるごと使え、**税金は0円**でしたの。2026年からはこれが9年に延びたので、**60歳でiDeCo・65歳で退職金という「5年ずらし」は、もう効きません**わ。控除を別々に使うには、iDeCo一時金のあと**10年以上**空ける必要がありますの。

### 計算例3：60歳で退職金2,000万円、65歳でiDeCo800万円（退職金が先）

- 会社：22歳〜60歳の勤続38年、60歳で退職金2,000万円 → 控除2,060万円の内側なので**0円**
- iDeCo：40歳〜60歳の加入20年、65歳で一時金800万円

| 項目 | 計算 |
|---|---|
| ふつうの控除額 | 40万円×20年＝800万円 |
| 前回（退職金）の期間の縮め方 | 2,000万円＜2,060万円なので、（2,000万円−800万円）÷70万円＋20＝37.1 → **37年**（22歳〜59歳）とみなす |
| 重複期間 | iDeCoの40歳〜60歳のうち、59歳までの**19年** |
| 差し引く額 | 40万円×19年＝760万円 |
| 今回の控除額 | 800万円−760万円＝40万円 → 80万円未満なので**80万円** |
| 退職所得 | （800万円−80万円）×1/2＝360万円 |
| 税金の合計 | 所得税 約29.9万円＋住民税36万円＝**約65.9万円** |

5年ずらしても、控除はほぼ残りませんわ。こちらの順番は「前年以前19年内」が対象なので、60歳で退職金を受け取ったら**iDeCoを一時金で受け取って調整を避けられるのは80歳以降**。iDeCoは75歳までに受け取りを始める決まりですから、**実質的に回避は不可能**ですの。

退職金が控除の内側に収まる人は、使い残した分（計算例3なら60万円分＝約1.5年分）が後に回るだけ。**退職金がある会社員は、iDeCoの一時金に退職所得控除はほとんど残らない**と覚えておけば、まず外しませんわ。

## 受け取る前にやっておくこと

計算ができても、書類がなければ控除は正しく使えませんの。

- **退職金の「退職所得の源泉徴収票」を捨てない**。iDeCo一時金を受け取るとき、前年以前19年内の退職金がわかる書類として求められますわ
- **「退職所得の受給に関する申告書」を必ず出す**。出さないと一時金から**20.42%**が源泉徴収され、確定申告で取り戻すことになりますの（[国税庁 No.1420](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm)）
- **退職金の額と支給時期を人事部で確認する**。退職一時金と企業年金の一時金が別々に出る会社もあり、どちらも退職所得として合算されますわ
- **企業型DCからiDeCoに移した人は、加入期間を通算で確認する**。会社の勤続期間と重なる部分は上乗せになりません

## よくある質問

### iDeCoの退職所得控除は、退職金とは別枠ですか？

**同じ年なら別枠になりません**。合算して1回分ですわ。別の年に受け取っても、iDeCoが先なら9年、退職金が先なら19年の範囲で、重なった年数分の控除が削られますの。退職金がない人（自営業・フリーランス・退職金制度のない会社）だけが、iDeCoで控除を丸ごと使えますわ。

### 控除オーバーしたら、どれくらい税金がかかりますか？

はみ出した額の**半分**に、所得税（5%〜）と住民税10%がかかりますの。たとえば控除を200万円オーバーなら、退職所得100万円で所得税 約5.1万円＋住民税10万円＝**約15.1万円**ですわ。オーバー分を年金で受け取れば、60〜64歳なら公的年金等控除（65歳未満は最低60万円）を使える可能性がありますの。

### パートで働いていて退職金がない場合は？

会社に退職金制度がなければ、iDeCoの加入年数分の控除を**丸ごと使えます**わ。加入10年なら400万円まで非課税。パート先の退職金規程は一度確認しておいてくださいまし。

### 掛金を途中で止めた期間も、加入年数に入りますか？

**入りません**。掛金を出していない運用指図者の期間は、退職所得控除の年数に数えられませんの。たとえば加入20年のうち5年止めていれば、控除は800万円ではなく600万円（15年分）ですわ。

## まとめ｜計算を知ると、受け取り方の答えが変わる

- 退職所得控除は**加入20年で800万円、30年で1,500万円**。iDeCoでは掛金を出していた年数で数える
- 控除を超えた分は**1/2だけ**課税。分離課税なので給与と合算されない
- **会社の退職金と同じ年なら控除は1回分**。iDeCoの加入年数は上乗せされないことがほとんど
- 別の年でも、**iDeCoが先なら9年（2026年〜）、退職金が先なら19年**の範囲で、重なった年数分の控除が削られる
- 退職金がある会社員は、**iDeCoの一時金に控除はほとんど残らない**前提で、年金受け取りを軸に考える

自分がどのパターンか分かったら、[iDeCo受け取り方はどれが一番お得？一時金・年金・併用の判定表](/posts/2026-06-16-ideco-payout-strategy-tax-optimization/)で受け取り方を決めてくださいまし。ふん、ここまで読んだあなたなら、もう「iDeCoは出口も非課税」なんて雑な説明には騙されませんわね 🌹

※本記事は一般的な情報提供を目的としたもので、計算例は所得税（復興特別所得税込み）と住民税10%による概算ですわ。令和9年分からは防衛特別所得税が加わり復興特別所得税が引き下げられますが、国税庁によれば合計税率は変わりません。実際の税額は個人の状況で異なりますので、受け取りの前に税務署・税理士・運営管理機関へご確認くださいませ。
