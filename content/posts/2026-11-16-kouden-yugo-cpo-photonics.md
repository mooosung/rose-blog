## 光電融合とは？ひとことで言うと「電気の配線を、できるところから光に置き換える」

コンピューターの中では、データは**電気信号**として銅の配線を走っておりますわ。ところが、AIの計算で扱うデータ量が増え、信号が速くなるほど、電気には困った性質が出てきますの。

| 電気信号の弱点 | 何が起きるか |
|------|------|
| 速くするほど信号が弱る | 弱った信号を補うための回路（DSPなど）が必要になり、電力を食う |
| 距離が長いほど損失が増える | 配線が長いほど電力がかさむ |
| 熱になる | 電力のロスはそのまま発熱。冷却にもまた電力が要る |

光は、電気に比べて**伝送中のエネルギー損失が圧倒的に少ない**のが強みですわ。長距離の通信では、すでに光ファイバーが当たり前に使われておりますわね。

そこで「**チップのすぐ近くまで光で運んで、電気で走る距離をできるだけ短くしよう**」という発想が生まれましたの。この技術の総称が**光電融合**（英語では Photonics-Electronics Convergence）ですわ。三井物産戦略研究所のレポートも、光電融合を「電気信号での伝送を光信号での伝送に置き換え、電力消費の課題を解決すると期待される技術の総称」と説明しておりますの。

### 「光電融合」と「シリコンフォトニクス」はどう違う？

ここ、混ざりやすいところですわね。

| 用語 | 何を指すか |
|------|------|
| **光電融合** | 電気と光を組み合わせて、電気の距離を短くする**考え方・技術の総称** |
| **シリコンフォトニクス** | シリコンのウェハの上に、光の通り道や変調器を作る**製造技術** |
| **CPO** | 光の変換部品をチップと同じパッケージに載せる**実装の方式** |

つまり、シリコンフォトニクスという**作り方**で光の部品を作り、CPOという**載せ方**で実現するのが、いまの光電融合の主流ですわ。光通信そのものの基礎は[光通信・光ファイバーとは？](/posts/2026-03-03-optical-communication-fiber-ai-stocks/)で説明しておりますの。

## 光電融合の4段階──NTTの「PEC」ロードマップで見る

光電融合は「どこまで光にするか」で段階が分かれますわ。いちばん分かりやすいのが、NTTが2025年10月の「NTT PR/IR DAY」で示した**PEC（光電融合デバイス）のロードマップ**ですの。

| 段階 | 光でつなぐ場所 | 状況（NTTの説明） |
|------|------|------|
| **PEC-1** | データセンター間・サーバー間 | IOWN 1.0として提供済み |
| **PEC-2** | コンピューターの**ボード間** | 光電融合スイッチ。**2026年Q4に商用サンプル**の見込み |
| **PEC-3** | ボード上の**パッケージ間** | 試作品を評価中。**2028年の製品化**を予定 |
| **PEC-4** | パッケージの中の**ダイ（チップ）間** | その先の目標 |

下に行くほど、光がチップの奥まで入り込んでいきますの。いまは**PEC-2の段階が実用化に入ったところ**、と覚えておけば十分ですわ。

NTTによると、PEC-2の光電融合スイッチでは、光通信モジュールから処理チップまでの距離を**約300mmから約30mmに縮める**そうですの。容量は102.4Tbpsで、スイッチ単体で**50%の電力削減**を見込んでいると説明されておりますわ。さらにPEC-3では、PEC-2の**10分の1以上の省電力化**が見えているとのことですの。

大阪・関西万博のNTTパビリオンでは、試作品の光電融合デバイスを使った計算環境で**消費電力8分の1**を実証したとも発表されておりますわ。

## CPO（Co-Packaged Optics）とは？光トランシーバーとの違い

いま光電融合の話題の中心にいるのが**CPO**ですわ。CPOを理解するには、**これまでのやり方**と比べるのが一番ですの。

### これまで：ボードの端に「差し込む」光トランシーバー

従来のデータセンターのスイッチでは、電気と光を変換する**光トランシーバー**を、機器の前面（フロントパネル）に差し込んでおりましたわ。USBメモリのように抜き差しできる部品で、「プラガブル」と呼ばれますの。

この方式だと、スイッチのチップから光トランシーバーまで、**数十cmの電気配線**を走らせる必要がありますわ。速度が上がるほど、この区間で電力が溶けていきますの。光トランシーバーや光モジュールの会社については[光インターコネクト・光モジュール株徹底解説](/posts/2026-04-06-light-interconnect-optical-modules-stocks/)で取り上げておりますわ。

### CPO：光の変換部品をチップの「すぐ横」に置く

CPOでは、光トランシーバーの中核部品である**光エンジン**を、スイッチのチップと**同じパッケージの上**に載せてしまいますの。

| 比べるところ | プラガブル光トランシーバー | CPO |
|------|------|------|
| 光の変換をする場所 | 機器の前面（ボードの端） | **チップと同じパッケージ上** |
| 電気が走る距離 | 数十cm | **数cm** |
| 消費電力 | 基準 | 三井物産戦略研究所は**およそ3分の1以下**と整理 |
| 信号を補正するDSP | 搭載 | 一般に不要 |
| 壊れたときの交換 | 1本ずつ抜き差しできる | パッケージごとになりやすい（課題） |

光ファイバーをパッケージから直接引き出せるので、前面のスペースの制約もなくなり、**つなげる本数（帯域）も増やせる**のが利点ですわ。

### CPOでは「レーザーを外に出す」のが主流

光エンジンのすぐ横には、ものすごく熱くなるスイッチのチップがありますわ。ところが、光を出す**レーザーは熱に弱い**部品ですの。

そこで、レーザーだけはパッケージの外に置いて、光ファイバーで光を送り込む「**外部光源（ELS：External Laser Source）**」方式が主流になりつつありますわ。後で出てくる古河電工は、この外部光源を作っている会社ですの。

## NVIDIAはどこまで進んだのか

「NVIDIA 光電融合」と検索されることが多いので、ここは事実だけを並べますわね。

### Spectrum-X Ethernet Photonics が量産入り

NVIDIAは2025年3月のGTCで、CPOを使ったネットワークスイッチ「**Spectrum-X Photonics**」（イーサネット）と「**Quantum-X Photonics**」（InfiniBand）を発表しておりましたわ。

そしてStorageReviewの2026年8月15日の記事によると、**Spectrum-X Ethernet Photonics が量産（full production）に入った**とのことですの。NVIDIAが示した効果は次のとおりですわ。

| 項目 | 従来の光トランシーバー型と比べて |
|------|------|
| レーザーの数 | **4分の1** |
| 消費電力 | **5分の1** |
| 障害が起きるまでの平均時間 | **10倍** |

GPUの数が数十万に増えると、光の部品も数十万単位で必要になりますわ。部品が減れば壊れる場所も減りますので、運用する側にとっては**電力より信頼性の改善のほうが大きい**、という見方もありますの。

### 製造は5社の分業

同じ記事では、NVIDIAがCPOスイッチの製造パートナーを工程ごとに明かしたことも伝えておりますわ。

| 工程 | 担当 |
|------|------|
| シリコンフォトニクスの製造 | **TSMC** |
| パッケージングとテスト | **SPIL**（台湾の後工程大手） |
| レーザーチップ | **Lumentum** |
| レーザーモジュールの組み立て | **TFC Communication**（中国） |
| スイッチ本体の組み立て | **Foxconn**（鴻海） |

ここに日本企業の名前は入っておりませんの。「NVIDIA採用」をうたう日本の銘柄情報を見かけたら、**会社自身が発表しているか**を必ず確かめてくださいまし。

このスイッチは、NVIDIAの次世代AI基盤「Vera Rubin」をつなぐためのものと位置づけられておりますわ。

### NTTとBroadcomの光電融合スイッチ

NVIDIAとは別の陣営として、NTTは**Broadcom**と組んでおりますの。NTTの説明では、NTTイノベーティブデバイスの光エンジンとBroadcomのスイッチASICを組み合わせ、台湾のAcctonが筐体に収め、**新光電気工業が基板製造とCPOモジュールの組み立て**を担当する体制ですわ。

光エンジンを**ソケット式**にして交換しやすくしているのが、NTTの差別化ポイントだそうですの。CPOの弱点である「壊れたときの交換」に正面から手を打っているわけですわね。

### 1社ずつ、どこで効いてくるか

**NTT（9432）** は、光電融合を国の通信インフラ構想（IOWN）の柱にしている会社ですわ。ただ、NTTは巨大な通信会社ですので、**光電融合が株価を動かすほどの売上になるのはまだ先**ですの。テーマとしては本命でも、銘柄としての値動きは通信事業で決まりますわ。

**古河電工（5801）** は、CPOで主流になりつつある**外部光源**を早くから手がけておりますの。レーザーをパッケージの外に出す流れが進むほど、この部品の出番は増えますわね。

**ウシオ電機（6925）** は、少しひねった立ち位置ですわ。光電融合では、光を出すレーザー（DFB-LD）の需要が急に増えておりますの。ところが、レーザーの中の細かい溝（回折格子）を作る装置の生産性が低く、供給が追いつかない──そこを**作る側の装置**で狙っておりますの。まさにツルハシのツルハシですわね。干渉縞のピッチ精度0.01nmを達成したと発表しておりますわ。

**QDレーザ（6613）** は、熱に強い**量子ドットレーザ**の会社ですわ。検索では「NVIDIA 光電融合 QDレーザ」という組み合わせも多いのですけれど、**NVIDIAとの取引を会社が発表した事実は、2026年11月15日時点で確認できませんでした**の。プレスリリースで確認できるのは、2023年の「光配線用シリコンフォトニクスチップ向けに6万個の量産受注」までですわ。小型株で値動きも大きいので、思惑だけで飛びつかないでくださいまし。

**新光電気工業**は、NTTの光電融合スイッチで重要な役を担っておりますけれど、2025年にTOBを経て**上場廃止**になっておりますわ。いまは株式市場から買えませんの。経緯は[ICパッケージ基板の記事](/posts/2026-03-05-pcb-ic-package-substrate-ibiden-ai/)の「新光電気工業はいまどうなっている？」にまとめてございますわ。

## 気をつけたい点──3つ

**1. 光にするのは「全部」ではない**

光電融合はまだ**スイッチ（ネットワーク機器）から**始まった段階ですわ。GPU同士をラックの中でつなぐような短い距離では、**銅線のほうがコストと信頼性で有利**という意見も根強いですの。NVIDIA自身も、ラック内のGPU接続にはいまも銅線（NVLink）を使っておりますわ。「光電融合で銅線が消える」わけではありませんの。

**2. 熱と保守はまだ課題**

熱いチップのすぐ横に光の部品を置く以上、熱対策は避けて通れませんわ。また、一体化した部品は1か所壊れると交換が大がかりになりますの。外部光源やソケット式は、まさにこの課題への答えとして出てきたものですわ。

**3. テーマ株は先に値段がつく**

「光電融合」という言葉がニュースに出るたびに、関連とされる小型株が大きく上下しますわ。売上として数字に出てくるのは、多くの会社で**2027年以降**の話ですの。決算で光電融合関連の売上がどれだけ出ているか、を確かめてから判断するのが安全ですわ。

## よくある疑問（FAQ）

**Q. 光電融合の読み方は？**
「こうでんゆうごう」ですわ。英語では Photonics-Electronics Convergence（PEC）と呼ばれますの。

**Q. 光電融合とCPOは同じもの？**
同じではありませんわ。光電融合は**技術の総称**、CPOはその中の**具体的な実装方式のひとつ**ですの。CPOはNTTの段階で言えばPEC-2あたりに当たりますわ。

**Q. 光電融合とシリコンフォトニクスの違いは？**
シリコンフォトニクスは、シリコンのウェハの上に光の回路を作る**製造技術**ですわ。光電融合を実現するための主要な手段のひとつ、という関係ですの。

**Q. 光電融合で何がうれしいの？**
いちばんは**電力**ですわ。AIデータセンターは電気が足りなくなっておりますので、通信にかかる電力が減れば、その分をGPUの計算に回せますの。電力・冷却まで含めた全体像は[AIツルハシ銘柄一覧](/posts/2026-07-14-tsuruhashi-investment-complete-guide/)で読むと分かりやすいですわ。

**Q. NTTの光電融合はいつ実用化？**
NTTの説明では、PEC-2の光電融合スイッチが**2026年Q4に商用サンプル**、PEC-3は**2028年の製品化**予定ですわ。

1. **光電融合は、電気の配線を光に置き換えて電力を減らす技術の総称**。光にする場所が、サーバー間 → ボード間 → パッケージ間 → チップの中へと奥に進んでいきますの
